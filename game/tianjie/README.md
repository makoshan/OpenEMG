# 掌天诀 · 四境试炼

单人、单手结印的第一人称实时 3D PVE 展示原型。天庭五手曾维系诸天，如今其中一只正在你的右手中苏醒；手环是压住神性的锁。开场约 12 秒，随后进行佩戴检查与三印练习，每印一次。

## 运行与构建

```sh
npm ci
npm run assets -- ../../app/game/tianjie/assets
npm test
npm run app
npm start
```

打开 http://127.0.0.1:4318 。`npm run app` 同时重建并复制到 App 的离线游戏目录；CI 检查源码重建与 App 产物完全一致。素材由仓库内 `app/game/tianjie/assets` 复用，公开素材有 SHA-256 校验。`npm run assets` 不带路径可下载公开模型/纹理，生成的 Logo 与远景请复用本仓素材。

## 操作与四关

Q 道指剑：24 伤害、不耗灵力、冷却 0.42 秒。E 破邪印：护身 1.05 秒、冷却 1.45 秒，命中前 0.32 秒内结印可反制。R 五雷诀：主目标 100 伤害、其他已现身目标 50 伤害、35 灵力、冷却 3.2 秒。灵力每秒恢复 8。

- **失序山门**：游魇、掠影、守山夜魇分批突袭；掠影会闪避连剑，清敌后山门打开。
- **悬天索桥**：清敌后山门向内打开，连续穿门来到深谷上的单人木吊桥（不黑屏切景）；木板随悬索下垂，两侧云鳐与琉璃蜻蜓妖来袭，玉色妖躯、虹彩薄翼，扑击前赤眼疾振；连续三次命中可打断扑击。清敌后用约 18 秒走完吊桥、穿过原亭近景门廊，沿崖下降至镜湖。
- **镜湖回廊**：镜影与悬空灵魄；破邪印打破镜障 3.5 秒，其间全额受伤，平时只承受 20% 伤害。
- **雷狱天台**：妖凰、石傀、执雷天像；五雷诀破石傀护甲，脚下落雷有 1.5 秒预警，移动出圈、闪身或护身可避。

共 12 敌，每过一境恢复 25 气血与灵力；全部镇伏后，再结一次五雷诀封印（无额外消耗）才胜利。气血为零失败。成败分别有全屏金色封印／赤色碎锁演出及结算。

Tab 或点击敌人血条换目标。自动前进、自动锁定让三手印足以通关；WASD 行走、空格闪身、右键环顾可选，P 暂停。触屏有技能与方向按钮。「测试」仅跳过冷却/灵力；「无敌」仅避免掉血，两者会标明并保存在本机。

## 手环接入

**现有 OpenEMG App 已接通真实分类器与游戏桥**，本次继续使用既有 `TianjieGame.band/inputResult`。在 App 中选「结印三招」、保持识别开启，再打开游戏。普通浏览器可明确选择键盘试玩，不会显示为硬件检查通过。

佩戴检查需用户确认位置、有效八路状态和连续 2 秒新鲜状态；过期、断流、异常或暂停不能通过。练习需先放松、再以 0.8–1 置信度识别对应手印；练习隔离于战斗，不消耗资源、不受攻击。断流会重置本次硬件检查，不拼接佩戴段。此检查验证 App 提供的状态与三次响应，不等于测量延迟、准确率或电极接触阻抗。

设备桥调用 `window.TianjieGame.inputResult({gesture:'sword',confidence:0.95})`，支持 sword/guard/thunder 并返回接受或拒绝原因；兼容 `input` 和 `tianjie:gesture`。手部为骨骼动画、腕姿来自既有 IMU，非完整手指追踪；`tianjie:feedback` 灯效事件仍标记 simulated，本次没有实体 LED 命令。

默认不上传玩家记录或肌电，手动导出仅含本局游戏事件。没有改采集、分类器、设备参数，也没有安装覆盖已运行的 App。

## 验证与范围

`npm test` 验证状态、战斗/关卡机制、佩戴门与模型皮肤权重。App 目录可运行 `check-game-window.cjs`、`check-game-onboarding.cjs`、`check-game-audio.cjs`，用生产离线沙箱及 IPC 验证合成输入；`check-game-chain.cjs` 还经过真实 MetaLive 组件。它们不连接设备。

近景、怪物、法术实时渲染；手部在 MIT WebXR 骨骼模型上细分，指甲改为表面着色，避免悬浮甲片；四关分别使用钟鼓、凌风、水吟、战鼓主题；离线 Web Audio 合成拨弦、笛音、铺底弦声及铜鼓，镜湖叠加流水与滴水环境声。三诀叠加起手、施放、冲击与余音，并有青剑、金印、紫雷手部光效；妖怪死亡会闪爆、扩散冲击环并碎散。它仍使用原型级角色与动画，并未达到完整 AAA 制作品质。素材与许可见 [ASSETS.md](ASSETS.md)。旧 Sites 链接为历史版本，当前代码以本仓为准。
