# C08B 共用主控上电自检固件 + 台架上电清单（2026-11-12 升级版）

状态：**已实现未验收（能编译、主机端单测与反例全过、引脚逐脚直核 R4U6/R4U6N 板文件；未上板、未刷机）。** 目标是板子到手当天零跳线判断主控与任一下层采集板能不能用。

适用主控与下层采集板组合（共用 20P 排线 `J_AFE`，零跳线自动识别）：

| 组合 | 主控板 | 下层采集板 | 自动识别条件 | 全过 `done_mask` |
|---|---|---|---|---|
| **16CH 双面** | `R4U6` / `R4U6N` | `D20` / `D20N`（双 ADS1298） | `id_a` 低 5 位 `=0x12` 且 `id_b` 低 5 位 `=0x12` | `0x03FF` |
| **8CH 单面** | `R4U6` / `R4U6N` | `D20-8CH` / `D20N-8CH`（单 ADS1298） | `id_a` 低 5 位 `=0x12` 且 `id_b ∈ {0x00, 0xFF}` | `0x03F5`（跳过 bit1/bit3） |
| **2CH 六触点** | `R4U6` / `R4U6N` | `ADS1292-2ch-R9`（单 ADS1292） | `(id_a & 0xDF) == 0x53` 且 `id_b ∈ {0x00, 0xFF}` | `0x03F5`（跳过 bit1/bit3） |

若 `id_b` 读回非空非全 1 的乱码（如 `0x80`），或 U1 没应答只剩 U2，均判为异常（不误降级为单芯片模式，`ADS_B_ID` 置失败位）。

## A 两颗芯片各做什么

| 芯片 | 上电后 | 结果从哪看 |
|---|---|---|
| U18 STM32L432 | 打开 AFE 缓冲 → 同时拉低 `ADS_PWDN` 与 `ADS_RESET` 50 µs（兼容 ADS1298 独立复位脚与 ADS1292 `J2.6 PWDN/RESET`）并等 200 ms `> t_POR` → 读 U1/U2 ID 自动识别 `16CH / 8CH / 2CH` → 写全套寄存器并逐个回读 → 内部约 1 Hz 测试方波采 2000 帧：2/8/16 路峰峰值、采样率、DRDY 同步（16CH）或 `PA4 AVDD_SENSE` 3.0 V LDO 电平（2CH）、状态字 → 输入短接采 1000 帧（2CH 保持 `CONFIG2=0xA0` 开启内部 2.42 V 基准）：底噪 RMS → I2C 读 IMU `WHO_AM_I` 和静止重力 → 打包 97 字节报告，每 500 ms 经 SPI3 发给 nRF | SWD 读 `g_report`，或 RTT 日志 |
| U13 nRF52840 | 拉高 `PWR_HOLD` 保持供电 → 打开调试口（Rev3 默认锁）→ 起 32 MHz 晶振 → SPIS 收 L432 报告（CRC 校验）→ 按 `report_expected_done(id_a, id_b)` 判全过 → 读 VBAT、VBUS、充电、按键、互锁状态 | 手机 BLE 广播（名字 **C08B**）、UART（`J301.5`，115200）、RTT、LED 闪码 |

10 个自检项（报告 `done_mask` / `fail_mask` 的位号）：

| 位 | 项 | 16CH (`D20`) 判据 | 8CH (`D20-8CH`) 判据 | 2CH (`ADS1292-R9`) 判据 |
|---|---|---|---|---|
| 0 | ADS_A_ID | `(id_a & 0x1F) == 0x12`（0x92） | 同左 | `(id_a & 0xDF) == 0x53`（0x53/0x73） |
| 1 | ADS_B_ID | `(id_b & 0x1F) == 0x12` | 跳过（要求 `id_b ∈ {0x00, 0xFF}`） | 跳过（要求 `id_b ∈ {0x00, 0xFF}`） |
| 2 | REG_A | 25 个寄存器写后读回一致 | 同左 | 10 个寄存器写后读回一致 |
| 3 | REG_B | U2 同上 | 跳过 | 跳过 |
| 4 | DRDY | 500 Hz ±2%（490–510 Hz）+ U1/U2 同步 | 500 Hz ±2%（外部 2.048 MHz 晶振） | 500 Hz ±4%（480–520 Hz，内部 512 kHz RC） |
| 5 | STATUS | 每帧状态字高 4 位 `= 0xC` | 同左 | 24 位状态字高 4 位 `= 0xC` + 全程 `PA4 AVDD_SENSE = 1` |
| 6 | TEST_SIG | 16 路峰峰值 `0.5–5 mV` 且中位数 `±20%` | 8 路同左 | 2 路峰峰值 `0.5–5 mV` 且中位数 `±20%` |
| 7 | NOISE | 16 路短接底噪 RMS `100 nV–5 µV` | 8 路同左 | 2 路同左（`LSB = 48.08 nV`） |
| 8 | IMU_ID | `WHO_AM_I = 0x6A` | 同左 | 同左 |
| 9 | IMU_G | 静止加速度模长 `0.8–1.2 g` | 同左 | 同左 |

说明：
- SPI 字节间隔与帧末 `CS` 拉高前延时（`t_SCCS`）均已统一放宽至 `10 µs`，同时满足 ADS1298（`2.048 MHz`）与 ADS1292（内部 `512 kHz`，`t_SDECODE = t_SCCS = 4 t_CLK = 7.81 µs`）的时序要求。
- 2CH 模式下，`ADS1292-2ch` 的 `J2.3` 将 `AVDD_SENSE`（模拟 3.0 V 经 `R26 100 kΩ`）送到主控 `J_AFE.18`（`PA4 / DRDY_B`）；L432 在 2CH 分支先切 `P_DOWN` 10 µs 放净寄生电容残荷（防开路假阳性），再保持 `P_NONE` 无上下拉高阻输入（防 `40 kΩ` 分压及 `3.3 V` 倒灌），初检及两个采样阶段逐帧核对 `PA4 == 1`，异常计入 `bad_status`（置位 bit5 `STATUS`）。
- `TEST_SIG` 走芯片内部测试源（`MUX=101`），证明 PGA、基准与 ADC 正常，不覆盖外部电极、ESD 和输入 RC。

## B 结果怎么读

**手机（不用接调试器）**：nRF Connect 扫描，名字 `C08B`，厂商数据是公司号 `0xFFFF`（2 字节）后面跟 10 字节结果（可直接把复制出的十六进制串喂给 `python3 -B tools/decode_bringup.py --ble-hex "<HEX>"` 自动判读 `PASS / FAIL / WAITING_L432`、识别 `16CH / 8CH / 2CH` 并检查 `VBUS + OE_N` 互锁状态；SWD/GDB 导出的 97 字节 `g_report` 可用 `--report-hex "<HEX>"` 逐通道展开）：

| 字节 | 含义 |
|---|---|
| 0 | 格式版本 = 1 |
| 1–2 | `done_mask`（小端：`16CH` 全过 `0x03FF`；`8CH / 2CH` 全过 `0x03F5`） |
| 3–4 | `fail_mask`（小端；还没收到 L432 报告时是 `0xFFFF`，全过为 `0x0000`） |
| 5 | nRF 状态位：bit0 晶振起振，bit1 收到 L432 报告，bit2 有 VBUS，bit3 在充电，bit4 按键按下，bit5 AFE 缓冲被关（`OE_N=1`） |
| 6 | `VBAT ÷ 20 mV` |
| 7 | 报告序号低 8 位（每次开机从 1 起，在涨说明 L432 一直在发） |
| 8–9 | `id_a`、`id_b`（例如 `92 92`=16CH，`92 00`=8CH，`53 00`=2CH） |

**LED（D401）**：5 Hz 快闪 = 还没收到 L432 报告；1 Hz 慢闪 = 当前板型全过（`fail=0` 且 `done == expected_done`）；闪 N 下停一下 = 第 N−1 项没过（例如闪 7 下 = `TEST_SIG`）。

**串口**：`J301.5`（`MCU_TX`）接 USB-串口的 RX，地接 `J301.1`，115200 8N1。每收到新结果打印识别到的板型（`16CH 双片ADS1298` / `8CH 单面ADS1298` / `2CH 六触点ADS1292`）及对应有效通道数的方波与底噪数值，每 5 s 打一行状态。

## C 台架上电清单（第一次上电按顺序做）

不接人体。电极口空着或接台架信号源。

**供电只从 J401（电池口）进**：台架电源接 `J401.1`（VBAT）和 `J401.2`（GND），3.9 V。不要从 `J301.2` 往 3V3 灌电：U15（TLV75533P）没使能时输出端接着 120 Ω 放电电阻，输入端没电时还会被输出倒灌，超出手册绝对最大额定值。`J301.2` 只给调试探针当电平参考（VTref），探针不往外供电。板子靠按键 SW300 开机，nRF 跑起来后由 `PWR_HOLD` 接着供电。

| 步 | 做什么 | 看什么 | 不对就 |
|---|---|---|---|
| 1 | 目检：主控背面 `U18/U16/U3/U2/U10/J_AFE` 与下层采集板芯片/座子 1 脚方向，对各自制造包的 `polarity.png` | 1 脚标记全部对上 | 停，拍照 |
| 2 | 不接电源、不插 USB。量 3V3 对地、VBAT 对地电阻 | 不短路（> 1 kΩ） | 停，查短路 |
| 3 | 台架电源接 J401，3.9 V，限流 50 mA；不接采集板、**不插 USB**。先不按键，再按住 SW300 | 不按键电流接近 0；按住时 `3V3 = 3.3 V`，无元件发热；松手掉电 | 断电查 |
| 4 | 烧 nRF：探针接 `J301.1` 地、`J301.2` VTref、`J301.3` SWDIO、`J301.4` SWDCLK、`J301.6` 复位。**按住 SW300**，`pyocd flash -t nrf52840 build/nrf.hex`（或 `nrfjprog --recover` 后 `--program`）。LED 开始 5 Hz 快闪后再松手 | 松手后板子保持上电；手机扫到 `C08B`，`fail = 0xFFFF`；串口打印「自检开始」「32 MHz 晶振：起振」 | 松手掉电查 `D3 / PWR_HOLD`；无广播查晶振 |
| 5 | 烧 L432（**二选一**）：① **免焊线 USB DFU（R4U6/R4U6N 推荐）**：关机 → 插上 USB 线到 `J400` → 短按 SW300 开机（`BOOT0 = VBUS_SENSE ≈ 2.98 V`，L432 直接进 ROM DFU `0483:DF11`）→ `dfu-util -a 0 -s 0x08000000:leave -D build/l432.bin` → **拔掉 USB**，长按关机再短按开机；② **SWD 焊盘**：不插 USB，探针接 `J302.2` SWDIO、`J302.1` SWCLK，`pyocd flash -t stm32l432kc build/l432.hex` | 拔掉 USB、没接采集板时：`ADS_A_ID` 不过（读到 `0x00/0xFF`），IMU 两项应过（`done=0x0301, fail=0x0001`） | DFU 不出现查 `J400 / R209 / R210 / U18.31`；IMU 不过查 `U16` |
| 6 | 关机（长按 3 s 松手），关台架电源。接 20P 排线到下层采集板（主控 `J_AFE` 第 `k` 脚对采集板第 `21−k` 脚；**确保不插 USB**），限流放到 150 mA，上电后短按 SW300 | 电流比第 5 步增加（16CH 最高，8CH 次之，2CH 最低），无异常发热 | 电流猛增立刻断电 |
| 7 | 等约 10 s（自检约 7 s） | 手机 `fail = 0x0000`，`done = 0x03FF`（16CH）或 `0x03F5`（8CH/2CH）；LED 1 Hz 慢闪；串口打印对应板型与 2/8/16 路方波、底噪 | 按 `fail` 位查：`ADS_A_ID` 查排线与供电；`STATUS` 在 2CH 下同时核模拟 3.0 V LDO（`AVDD_SENSE`） |
| 8 | 换电池：长按 3 s 松手关机 → 拆台架电源 → 确认 LED 灭 → 接电池到 J401 → 短按 SW300 | 报告序号从 1 重新开始，随后自检全过；`VBAT` 在 `3.6–4.2 V` | 序号未归 1 说明未真断电 |
| 9 | 长按 SW300 3 s 后松手 | 松手后断电（LED 灭、广播消失） | — |
| 10 | 互锁与 `BOOT0=VBUS_SENSE` 联合验收（**不贴 JP701**，四小步全过才算通过）：① 不插 USB 电池开机等自检全过：`bit5 (OE_N) = 0`，量主控板 `R823`（或 16CH/8CH 采集板 `V4_R804` / 2CH 板 `J2.6`）`AFE_PWDN ≈ 3.3 V`；② **保持开机运行中**插上 USB（`J400`）：`bit5` 立刻翻为 `1`，串口「AFE 缓冲 关」，量 `AFE_PWDN < 0.3 V`（硬件互锁切断模拟口与复位脚）；③ **插着 USB** 长按 3 s 关机、再短按开机：因 `R4U6/R4U6N` 的 `U18.31 BOOT0 = VBUS_SENSE`，L432 进入 ROM USB DFU（电脑枚举到 `0483:DF11`，nRF 不再收到 L432 报告，`fail=0xFFFF`），同时 `bit2=1, bit5=1` 且量 `AFE_PWDN < 0.3 V`；④ 拔掉 USB，长按关机再短按开机：恢复自检全过 | 四条全对 | 任何一条不对 = 互锁失效，**停，别接人** |

注意：
- nRF 的 `P0.17`（`OE_N`）只能设成输入，严禁推挽输出低（避免与 U10 对拉削弱互锁）。
- 插着 USB 又想采 AFE，只能在台架上贴 `JP701`（0 Ω），且在 `R4U6/R4U6N` 上必须**先电池开机进用户固件、再插 USB**（否则插着 USB 冷开机会进 ROM DFU）。贴了 `JP701` 的板严禁接人。

## D 编译与检查

```bash
PY=host/.venv-emg/bin/python zsh check.sh
make                             # 只编译：build/l432.hex、build/nrf.hex
```

- `tools/pins.py` 直接解析定稿板文件 `C08B-main-R4U6.epcb2` 与 `C08B-main-R4U6N.epcb2`（核对 L432 23 个信号脚含 `U18.31 PH3=VBUS_SENSE`、nRF 15 个信号脚），并包含两条必败反例（篡改 `XIAO_CS` 网名 + 喂入缺 `BOOT0=VBUS_SENSE` 的旧版 `r4u2-readback.json`）。
- `host_test/test_host.c` 覆盖 CRC、16CH/8CH/2CH 模式识别、期望掩码、B 片乱码/单活异常拦截、24 位补码与峰峰值/底噪门限的正反例测试。
- `tools/decode_bringup.py` 提供零依赖命令行解码（`--ble-hex` 自动兼容 10B 值 / 12B 含公司号 / 23B AD 载荷 / 31B 完整广播 PDU，`--report-hex` 校验并解析 97 字节 `c08b_report_t`，检测 `VBUS=1 & OE_N=0` 互锁旁路危险态；`--self-test` 已纳入 `check.sh` 与云端 CI）。

## E 边界说明

- 未上板、未刷机；采样率与底噪门限为台架初值，首板实测后收紧。
- 国产替代芯片（如芯佰微 CBM24AD98Q）若 `ID` 寄存器与 TI ADS1298（`0x92`）不同，需先实测 `ID` 值再更新 `ADS1298_ID_OK`。
- `VBUS_SENSE` 在 `R4U6/R4U6N` 上为 `R209=68 kΩ / R210=100 kΩ` 分压（`5.0 V` 时约 `2.98 V`），同时满足 nRF GPIO 与 STM32L432 `BOOT0` 的高电平阈值。
- BLE 仅发不可连接自检广播，正式高速采集流固件另仓维护。
