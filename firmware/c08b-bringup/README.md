# C08B 主控上电自检固件 + 台架上电清单（2026-11-09）

状态：**已实现、能编译、引脚逐脚对过 R4U6 板网表，独立复核的 P0 两条、P1 四条已改；没上板、没刷机。** 目标是板子到手当天判断能不能用。

适用：共用主控板（R4U6）+ 2ch/8ch/16ch 下层采集板，经 20P 排线 J_AFE 互联。

## A 两颗芯片各做什么

| 芯片 | 上电后 | 结果从哪看 |
|---|---|---|
| U18 STM32L432 | 打开 AFE 缓冲 → 复位两片 ADS1298 → 读 ID → 写 25 个寄存器并逐个回读 → 测试方波（约 1 Hz，U1 产生、U2 接收同一个信号）采 2000 帧：16 路峰峰值、采样率、两片 DRDY 同步、状态字 → 输入短接采 1000 帧：16 路底噪 → I2C 读 IMU 的 WHO_AM_I 和静止重力 → 打包 97 字节报告，每 500 ms 经 SPI3 发给 nRF | SWD 读 `g_report`，或 RTT 日志 |
| U13 nRF52840 | 拉高 PWR_HOLD 保持供电 → 打开调试口（Rev3 默认锁）→ 起 32 MHz 晶振 → SPIS 收 L432 报告（CRC 校验）→ 读 VBAT、VBUS、充电、按键、互锁状态 | 手机 BLE 广播（名字 **C08B**）、UART（J301.5，115200）、RTT、LED 闪码 |

10 个自检项（报告 `done_mask` / `fail_mask` 的位号）：

| 位 | 项 | 过的标准 |
|---|---|---|
| 0 | ADS_A_ID | U1 ID 低 5 位 = 0x12（ADS1298 = 0x92） |
| 1 | ADS_B_ID | U2 同上 |
| 2 | REG_A | U1 写的寄存器全部读回一致（CONFIG2 保留位 7:6 不比） |
| 3 | REG_B | U2 同上 |
| 4 | DRDY | 采样率 500 Hz ±2%；两个阶段里 DRDY_A 来时 DRDY_B 也是低、读完 U1 后 DRDY_B 已被 SCLK 清高；没超时 |
| 5 | STATUS | 两个阶段每帧状态字高 4 位 = 0xC |
| 6 | TEST_SIG | 16 路方波峰峰值都在 0.5–5 mV，且都在中位数 ±20% 内 |
| 7 | NOISE | 16 路短接底噪 RMS 在 100 nV–5 µV（下限防数据卡死） |
| 8 | IMU_ID | WHO_AM_I = 0x6A |
| 9 | IMU_G | 静止加速度模长 0.8–1.2 g |

门限是按手册典型值放宽的初值，第一次上板后按实测改。TEST_SIG 不经过电极输入脚（MUX=101），只证明每路 PGA、ADC 正常，不覆盖电极、ESD 和输入 RC；U2 的方波来自 U1，经两片 17/18 脚和 V4_REF1/V4_REF2 走线。两片同步看 DRDY 那一项。

## B 结果怎么读

**手机（不用接调试器）**：nRF Connect 扫描，名字 `C08B`，厂商数据是公司号 0xFFFF（2 字节）后面跟 10 字节结果：

| 字节 | 含义 |
|---|---|
| 0 | 格式版本 = 1 |
| 1–2 | done_mask（小端） |
| 3–4 | fail_mask（小端；还没收到 L432 报告时是 0xFFFF） |
| 5 | nRF 状态位：bit0 晶振起振，bit1 收到 L432 报告，bit2 有 VBUS，bit3 在充电，bit4 按键按下，bit5 AFE 缓冲被关 |
| 6 | VBAT ÷ 20 mV |
| 7 | 报告序号低 8 位（每次开机从 1 起，在涨说明 L432 一直在发） |
| 8–9 | 两片 ADS 的 ID |

全过时 done = `0x03FF`、fail = `0x0000`。广播本身也证明了 nRF、晶振、射频和天线这一路是通的。

**LED（D401）**：5 Hz 快闪 = 还没收到 L432 报告；1 Hz 慢闪 = 全过；闪 N 下停一下 = 第 N−1 项没过（例如闪 7 下 = TEST_SIG）。

**串口**：J301.5（MCU_TX）接 USB-串口的 RX，地接 J301.1，115200 8N1。每收到新结果打印一份完整报告（16 路方波和底噪数值），每 5 s 打一行状态。

## C 台架上电清单（第一次上电按顺序做）

不接人体。电极口空着或接信号源。

**供电只从 J401（电池口）进**：台架电源接 J401.1（VBAT）和 J401.2（GND），3.9 V。不要从 J301.2 往 3V3 灌电：U15（TLV75533P）没使能时输出端接着 120 Ω 放电电阻，输入端没电时还会被输出倒灌，超出手册绝对最大额定值。J301.2 只给调试探针当电平参考（VTref），探针不往外供电。板子靠按键 SW300 开机，nRF 跑起来后由 PWR_HOLD 接着供电。

| 步 | 做什么 | 看什么 | 不对就 |
|---|---|---|---|
| 1 | 目检：U18、U16、U3、U2、U10、J_AFE（主控背面）和 V4_U1/U2、FPC1/FPC3（采集板）1 脚方向，对 `polarity-*.png` | 1 脚标记对得上 | 停，拍照 |
| 2 | 不接电源、不插 USB。量 3V3 对地、VBAT 对地电阻 | 不短路（> 1 kΩ） | 停，查短路 |
| 3 | 台架电源接 J401，3.9 V，限流 50 mA；不接采集板。先不按键，再按住 SW300 | 不按键时电流接近 0（LDO 没开）；按住时 3V3 = 3.3 V，没有元件发热；松手 3V3 掉电（nRF 还没烧，没人拉 PWR_HOLD）。记下按住时的电流（没有基线） | 断电查 |
| 4 | 烧 nRF：探针接 J301.1 地、J301.2 VTref、J301.3 SWDIO、J301.4 SWDCLK、J301.6 复位。**按住 SW300**，`pyocd flash -t nrf52840 build/nrf.hex`。U13 是 Rev3，出厂调试口锁着：pyocd 会整片擦除解锁；用 nrfjprog 先 `nrfjprog --recover`，再 `nrfjprog --program build/nrf.hex --sectorerase --verify --reset`。固件第一次跑会自己复位一到两次（写 PSELRESET；APPROTECT 如果烧录工具没写过也会写一次），LED 开始 5 Hz 快闪后再松手 | 松手后板子保持上电；手机扫到 C08B，fail = 0xFFFF；串口有「自检开始」「32 MHz 晶振：起振」。之后接调试器读 RTT 时也按住 SW300（调试器复位 nRF 会放开 PWR_HOLD，板子会掉电），或用不复位的方式连接 | 松手就掉电查 D3 / PWR_HOLD；看不到广播先查晶振（bit0） |
| 5 | 烧 L432：探针接 J302.2 SWDIO、J302.1 SWCLK，地和 VTref 仍从 J301 取，`pyocd flash -t stm32l432kc build/l432.hex` | 没接采集板：ID 两项不过（ID 读到 0x00 或 0xFF），其余 ADS 项跳过；IMU 两项应过。记下稳定电流，第 6 步拿它比 | IMU 不过查 U16 焊接和 I2C 上拉 |
| 6 | 关机（长按 3 s 后松手），关台架电源。接 20P 排线到采集板（看清排线朝向：主控 J_AFE 第 k 脚对采集板第 21−k 脚），限流放到 150 mA，上电后短按 SW300 | 电流比第 5 步多（两片 ADS + 电荷泵，估几十 mA，未实测） | 电流猛增立刻断电 |
| 7 | 等约 10 s（自检约 7 s） | 手机 done = 0x03FF、fail = 0x0000；LED 1 Hz 慢闪；串口 16 路方波峰峰值彼此接近，底噪几 µV 以内 | 按 fail 位查：ID 不过查排线和 3V3_AFE；REG 不过查 SPI；DRDY 不过查 2.048 MHz 晶振 V4_X1 和 DRDY_B 走线；TEST_SIG 单路异常是那一路的 PGA/ADC；U2 八路一起偏低或为零，先查两片 17/18 脚和 TP901–904（U1 送出的方波在这几个点） |
| 8 | 换电池：长按 3 s 后松手关机 → 关掉并拆下台架电源 → 确认 LED 灭 → 接电池到 J401 → 短按 SW300 | LED 先回到 5 Hz 快闪，广播字节 7（报告序号）从 1 重新开始，随后自检照常全过；VBAT 在 3.6–4.2 V | 序号没从头开始说明板子没真断电，重做 |
| 9 | 长按 SW300 3 s，然后松手 | 松手后断电（LED 灭、广播消失）。按住期间按键本身就供着电，要松手才断 | — |
| 10 | 互锁（**不贴 JP701**），三条都过才算互锁验收：①不插 USB，开机等自检完：状态位 bit5 = 0，串口「AFE 缓冲 开」，自检全过；量 R823 两端（AFE_PWDN 对地）约 3.3 V；②插上 USB（J400）：bit5 翻成 1，串口「AFE 缓冲 关」（bit2 = VBUS 只作参考，它不在互锁链路上，VBUS 偏低时可能读不到）；③插着 USB 长按关机、再短按开机，等自检完：ADS_A_ID、ADS_B_ID 都不过（ID 读到 0x00），**并且** R823 两端 < 0.3 V（只看 ID 不够：两个缓冲器只要关掉一个 ID 就读不到，PWDN 那路所在的 U2 OE 脚虚焊时查不出）；拔掉 USB，关机再开机，恢复全过 | 三条全对 | 任何一条不对 = 互锁失效，**停，别接人** |

注意：
- 只看「插 USB 后 bit5 = 1」不够：L432 没跑或 PC14（ANA_EN）坏了时 OE_N 本来就是 1，所以第 10 步要前后对照，并量 AFE_PWDN。
- nRF 的 P0.17（OE_N）只能设成输入。它和 U10 推挽输出接在同一根线上；设成输出低时会和 U10 对拉到 1.2–2.1 V（推算），插着 USB 时缓冲器可能半开，削弱互锁。正式固件也照此写死（11-10 原理图审查 P1）。
- 插着 USB 又想采 AFE，只能在台架上贴 JP701（0 Ω）解互锁。贴了 JP701 的板不许接人。本固件里 nRF 始终把 BENCH_EN 拉低；另外复核按分压估算 R706（1 MΩ）让 BENCH_EN 拉高后 Q701 栅极只有约 0.3 V（未实测），软件本来也解不开。
- 开机或烧录时一直按着 SW300 不会触发长按关机，要先松开过一次才开始计时。
- 烧 nRF 会覆盖 0 地址起的 flash，包括出厂可能带的任何 bootloader。

## D 编译与检查

```bash
zsh check.sh                     # 引脚核对（含必须报红的反例）→ 干净重编 → 主机端测试 → 向量表与符号 → SHA-256
make                             # 只编译：build/l432.hex、build/nrf.hex
```

- 主机端测试失败会让 `check.sh` 退出码非 0（11-09 把测试断言改坏跑过一次，报「编译或主机端测试失败」）。
- 工具链：PlatformIO 自带 xPack arm-none-eabi-gcc 12.3.1（带 newlib-nano），`TC=` 可换。
- 头文件：PlatformIO 包 framework-cmsis、framework-cmsis-stm32l4@1.7.4（`pio pkg install -g -t platformio/framework-cmsis-stm32l4`）、framework-arduinoadafruitnrf52-seeed 里的 nrfx/mdk（8.30.2，没有 APPROTECT 外设定义，固件直接写地址 0x40000558）。`PIO_PKG=` 可换路径。
- 引脚唯一来源是 `tools/pins.py`：表里每一脚都对照 R4U6 板网表（`../../hardware/common-mainboard/mainboard-r4u6/r4u6-readback.json`）核对，并生成 `l432/pins.h`、`nrf/pins.h`。封装脚号表：L432 UFQFPN32 按 DS11451（与原理图第 5 页标签一致）；nRF52840 QFN48 按 Nordic 规格书「QFN48 pin assignments」（2026-11-09 从 docs.nordicsemi.com 取，与原理图第 2 页一致）。

## E 没做

- 没上板、没刷机。门限是初值。HSI16 本身约 ±1%，采样率 ±2% 的窗口余量偏紧，实测超窗先核时钟再判板子。
- 采集板如果贴的是国产替代（CBM24AD98Q），先核它的 ID 值再用 ID 判据。
- VBUS_SENSE 是 VBUS/2 当数字口读，5 V 时约 2.5 V，离 nRF 的 VIH（约 2.31 V）余量小；bit2 读不到时先量这个脚。
- MDK 8.30.2 的 SystemInit 勘误表不认识 Rev3，走默认分支，具体套了哪几条勘误修正没逐条核。
- USB 没用（L432 的 USB 需要 HSI48 + CRS，这份固件不碰）。
- BLE 只发不可连接广播，不建连接、不传数据流；正式采集固件另写。
- IMU 只读加速度，陀螺仪没测。
