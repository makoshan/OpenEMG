## 使用

从仓库根运行检查，不连接设备：

```sh
uv run --no-project --with numpy --with scipy python firmware/dsp-f03/check.py
uv run --no-project --with numpy --with matplotlib --with scipy python firmware/dsp-f03/noise_budget.py
uv run --no-project --with numpy --with matplotlib python firmware/dsp-f03/demo.py
```

系数重建：`uv run --no-project --with numpy --with scipy python firmware/dsp-f03/generate.py`，随后必须重跑检查。目标集成需要v12_dsp.h、v12_dsp.c、coefficients.h；probe.c仅供主机检查。按单调用者串行执行，不使用堆或访问设备。

本地记录格式为每行一个JSON事件：`{"packet_hex":"实际F01包的十六进制","mtu":247}`，断连为`{"disconnect":true}`。没有真实BLE抓取入口；须由后续采集端输出符合F01字节契约的记录。

```sh
uv run --no-project --with numpy python firmware/dsp-f03/replay.py /绝对路径/events.jsonl /绝对路径/新输出目录 --fs 4000
```

可加`--notch`；默认拒绝真实来源标签，明确使用`--allow-real`才接受。标签不能认证真实性。输出目录须不存在，防止覆写证据；events.jsonl逐字节保存，samples.csv同时保留状态字、8路原始码、8路滤波值，result.json记录来源/输入/输出哈希及诊断。空记录、拒包或时间异常退出2；完整解析退出0只代表回放运行完成。

## 数值与时间契约

- 2/4kSPS：15Hz二阶高通＋600Hz四阶低通，可选50Hz/Q30陷波；沿用FILTERS.md候选，不保证抑制漂移工频。
- 输出`filtered_fs`是ADC正满量程比例：原始码除以8388608，未自动换算µV；真实Vref、每路PGA增益和模拟网络必须随实测记录冻结。后续显示和分类不能覆盖原始码。
- 二阶高通的分子为b0×(1−z⁻¹)²，整数域先对24位原始码做二阶差分，再执行浮点递归。差分中间值最多约±33554430，int32可容纳。首码作为此前恒定输入，按稳态初始化；这是ADC后的计算，不能避免前端饱和。
- 前期普通float32直接形式在“偏置0.25满量程＋100Hz小信号”下，4kSPS计算误差约占小信号9.6%；首码锚点仍在偏置跳变后出现约1.67%误差，因此继续改为整数差分结构。最终4配置固定偏置及跳变后的合成对照误差均≤约0.0013%。这是C与双精度参考的一致性，不能当成实板噪声或动作识别收益。
- 正常分包保留状态。新会话、采样缺口、累计时间异常重置滤波状态，缺失采样不补造；序号回卷规则复用F01。坏包不推进采样状态。
- 时间核对同时检查相邻包间隔与段起点＋累计采样数，各自容差为半个名义周期＋对应时间3%。相邻检查发现突跳，累计检查发现持续频差。3%是临时筛查假设，既非实际时钟精度也非额定采样率保证；包内时间按周期推算，CSV明确标`estimated_timestamp_us`。
- 独立复核发现逐包核对漏掉“4k单帧包声明2k”，又发现单独累计容差可能掩盖长记录突跳；现两项并用并加入CLI反例。正确2k、约2%频差阳性通过；4k伪2k及正常运行10秒后100ms突跳被报告异常、退出2，突跳后恢复段重置。
- `dsp_ready`仅表示候选恢复样本数已到，不等于整个样本质量合格。恢复时长来自最大极点自然衰减到0.001：无陷波约104ms，Q30陷波约1.3195s；不是所有输入的稳定时间保证。
- `raw_code_at_rail`仅检查24位极值。PGA内部饱和、运动污染及未到满码的过载仍可能存在。采样后滤波不能修复这些问题。

## 检查范围

4配置共36000帧的大幅度逐点对照，37块拼接逐位一致；8通道隔离；24位极值；非法块整块拒绝且状态不前进；NaN、大整数及配置错误；固定偏置/偏置跳变的小信号；F01缺口、重复、坏包、时间跳变、断连及真实标签；实际CLI阳性、空记录、错采样率；4配置UBSan探针。逐帧清状态和缺口不清状态的错误版本均被检出。

首次检查因测试在合法块之后仍比较旧状态快照失败，修正检查并保留check-first-failed.log。动态库用不同路径加载正确/变异实现，避免系统缓存同名库使反例失效。results-before-small-signal.json是固定偏置问题暴露前的历史结果，不作为当前通过证据。

Cortex-M4硬浮点对象编译使用`-ffp-contract=off`，未使用fast-math。只是裸对象，未链接SDK/中断/SPI/BLE，不能证明板端处理时间、栈和无线队列满足要求。

## 更新噪声预算及方案选择

同一未实测线性模型，100kΩ电极/100pF线束、20–450Hz、无陷波：2kSPS网络噪声6.459µVrms，4kSPS为6.843µVrms，约增加5.95%。这是输入网络经sinc³和数字滤波后的ADC输入等效噪声，仅含电阻热噪声，未计ADC自身、1/f、漏电、RLD、带外折叠和射频/电源/运动。

4k/600Hz低通改善假设最差条件450Hz幅度约1.36dB，原始ADS数据54→108kB/s。继续优先台架对比2k/4k；真实BLE吞吐、线束和噪声取得前不冻结。限流电阻的位置/阻值与人体故障路径仍须电气复核，滤波实现不能关闭这些P0。
