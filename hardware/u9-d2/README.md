# U9 主控与 D2 双 34P 采集板开发稿

两块工程配合 16 路 D2 的 A/B 表带使用。嘉立创 EDA 专业版打开对应工程。此目录只提供可编辑设计，现有 D20 的制造包属于另一版采集板。

| 工程 | 版本与验证状态 |
|---|---|
| [U9 主控](u9-main.epro2) | 基于 U9 圆角修正版，将 U17 的器件型号和订货料号同步为 LTC4054ES5-4.2#TRPBF／C462648。修复底层 BUTTON_N 走线末条记录的分隔符，原生重导后 0 飞线，427 脚对照一致，仍有 1 项 Import Changes。此替代尚未做实物充电测试。 |
| [双 34P 采集板](d2-afe-development.epro) | 工程师布局的 D2 改版。新增 36 颗 ESD、8 颗上下拉和输入电容。FPC2.17 接 U2.39，FPC2.18 接 U2.47。原理图与 PCB 网络分组核对覆盖 593 个编号引脚。新版布线未完成，禁止据此投板。 |

U9 与采集板之间按 20 针反序排线（1 ↔ 20）。D2 两个电极座均为 FH34SRJ-34S-0.5SH(50)。从采集板正面俯视、北侧进线，A 尾接正面 FPC1，1 脚在左；B 尾接背面 FPC3，1 脚在右。改后工程尚待实物配合验证。

原报 5 项逐项在原生检查中找到。FPC3.27 对两条电源线的接触已消除；C1.1 对 $1N26 的两段走线及 FPC1.18 对 DOUT 的接触仍在。原报 163 个未连接项目来自 KiCad。最新版原生报告有 220 个连接错误对象、涉及 48 个网，另有 152 个间距类对象。四层 Gerber 扣除实际钻孔并合并金属孔壁后，独立铜图检测到 48 个网络断开、4 组异网互连，涉及电极输入、SPI 控制线、数字地与模拟地。FPC2.17 到 U2.39、FPC2.18 到 U2.47 各有导通，但控制线仍串到异网。

原生 DRC 对象数、断开的网络数及短接铜岛数采用不同计数单位。
