# U9 主控与 D2 双 34P 采集板开发稿

两块工程配合 16 路 D2 的 A/B 表带使用。嘉立创 EDA 专业版打开对应工程。此目录只提供可编辑设计，现有 D20 的制造包属于另一版采集板。

| 工程 | 版本与验证状态 |
|---|---|
| [U9 主控](u9-main.epro2) | 基于 U9 修正版，将 U17 的器件型号和订货料号同步为 LTC4054ES5-4.2#TRPBF／C462648。保留五脚 SOT-23 封装与原布线。此替代尚未做实物充电测试。 |
| [双 34P 采集板](d2-afe-development.epro) | 工程师布局的 D2 改版。新增 36 颗 ESD、8 颗上下拉和输入电容。FPC2.17 接 U2.39，FPC2.18 接 U2.47。原理图与 PCB 网络分组核对覆盖 593 个编号引脚。新版布线未完成，禁止据此投板。 |

U9 与采集板之间按 20 针反序排线（1 ↔ 20）。D2 两个电极座均为 FH34SRJ-34S-0.5SH(50)。从采集板正面俯视、北侧进线，A 尾接正面 FPC1，1 脚在左；B 尾接背面 FPC3，1 脚在右。改后工程尚待实物配合验证。

采集板目前的 KiCad 转换副本 DRC 检出 163 项未连接及 5 项异网短接。本轮重新布局了新增的保护器件、上下拉和电容。检查使用重新分配重复对象标识、重新铺铜后的转换副本。剩余短接报告涉及 C1.1 与 $1N26、FPC1.18 与 DOUT、FPC3.27 与正负 2.5 V 电源走线。继续布线时应以原生编辑器复核规则，完成后用实际导出的四层 Gerber、钻孔和飞针文件验证连通性，再比对 BOM 和贴片坐标。
