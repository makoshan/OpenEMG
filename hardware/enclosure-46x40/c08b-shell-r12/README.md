## C. 关键装配几何与边界说明（实测/导出 vs 假设）

1. **两块 PCB（采集板 D18 + 主控板 R2）四角同位 `(±19.05, ±15.75)` `M1.4` 螺丝 + 板间塑料柱/铜柱锁紧方案（见 `preview-pcb-standoffs.png`）**：
   - **同轴四孔坐标**：采集板 D18（`v12/c08b-afe-relayout-20261102/d18/`，厚 `0.80 mm`，`Z = 2.55..3.35 mm`）与主控板 R2（`v12/mainboard-r2-20261107/`，厚 `0.62 mm`，`Z = 6.79..7.41 mm`）均在相对板中心 **`(±19.05, ±15.75) mm`** 设 4 个同轴 `Ø1.70 mm` NPTH 无铜环安装孔，板间净距 **`6.79 - 3.35 = 3.44 mm`**（兼容市售标准 `M1.4 × 3.5 mm` 支柱或打印件 `3.44 mm` 支柱）。
   - **NW `(-19.05, +15.75)`、SW `(-19.05, -15.75)`、SE `(+19.05, -15.75)` 三角**：双板全层铜皮距孔心均 `≥ 2.043 mm`（净空圆 `Ø4.08 mm`），使用标准 **`OD = Ø2.50 mm, ID = Ø1.45 mm, H = 3.44 mm` 塑料柱/尼龙柱或黄铜柱** + `M1.4` 盘头螺丝（头径 `Ø2.50 mm`），与 `J_AFE` 20P FFC 回折弧（`y = -14.48..-13.00 mm`）及 `R821..R826` 全部零干涉。
   - **NE `(+19.05, +15.75)` 东北角防碰/防短路铁律**：主控板 R2 底面 `R209 (0402 VBUS)` 距孔心 `1.02..1.25 mm`（位于孔西侧）、底层 `VBUS` 走线距孔心 `1.033 mm`，顶面 `C53.1 (3V3)` 距孔心 `1.352 mm`。因此 **NE 角必须使用绝缘塑料柱/尼龙柱 + 尼龙 `M1.4` 螺丝（头径 `≤ Ø2.40 mm`）**，且支柱上段（`Z = 5.95..6.79 mm`）缩颈至 `OD = Ø2.00 mm`（对应 [`pcb_standoff_ne.step`](./pcb_standoff_ne.step)；若用市售 `Ø2.5 mm` 尼龙柱，上端西侧削 `0.5 mm` C 角避让 `R209`）。
   - **两种螺丝锁紧方式双兼容**：
     - **方式 1（双通内螺纹柱盒外对锁 —— 推荐）**：用 4 颗 `M1.4 × 3.5 mm` 双通内螺纹塑料柱/铜柱夹在两板之间，上下各拧 4 颗 `M1.4 × 2.5 mm` 螺丝（共 8 颗，NE 角用尼龙螺丝），在盒外先把两块 PCB + 20P FFC + 302025 电池锁成一体刚性内胆；放入底壳时，下方 4 颗螺丝帽（`Ø2.50×0.80 mm, Z=1.75..2.55`）正好落入底壳四角 `Ø4.50 mm` 支撑台顶部的 **`Ø2.80 × 深 0.90 mm` 沉头定位孔**，外圈环形台面（`Ø2.80..4.50 mm, Z=2.55`）稳托 D18 板底。
     - **方式 2（长螺丝一穿到底锁入底壳）**：用 4 颗空心隔柱（`pcb_standoff_std` × 3 + `pcb_standoff_ne` × 1）夹在两板之间，从主控板顶面（`Z = 7.41 mm`）往下穿 4 颗 **`M1.4 × 6 mm` 长螺丝**，直接旋入底壳沉孔底部的同轴 **`Ø1.25 mm` M1.4 自攻盲孔**（`Z = 1.00..1.65 mm`，孔底保留 `0.85 mm` 实心底壁防汗水）。
2. **嘉立创 3D 库高度虚标 vs 规格书真实高度（已双口径通过）**：
   - `U12`（`TPS3808G33DBVR`）与 `U17`（`USBLC6-2SC6`）均为标准 SOT-23-6，TI/ST 规格书最大高度 **`1.45 mm`**（顶面 `Z = 8.86 mm`），但嘉立创 3D 模型库将其画成 `1.69 mm`（顶面 `Z = 9.10 mm`）。
   - R12 上盖在 `U12`、`U17` 正上方设 `0.16 mm` 浅槽（槽顶 `Z = 9.26 mm`，顶壁实厚 `0.84 mm ≥ 0.80 mm`），对嘉立创虚高模型仍留 **`0.16 mm`** 净空，对真实器件留 **`0.40 mm`** 净空。
3. **假设与待实物确认项（标注“假设/未实测”）**：
   - **假设/未实测**：1 代 U.FL（IPEX1）同轴插头扣合顶高按 Hirose 标准最大值 `2.40 mm`（`Z = 7.41 + 2.40 = 9.81 mm`）建模，微凸窗内顶 `Z = 9.98 mm`（留 `0.17 mm` 净空）；2.4 GHz FPC 贴片天线按通用 `20.0 × 4.2 × 0.20 mm` 建模，须以实际采购天线的同轴出线方向（装配时将插头尾线朝北旋转对准 `y = 17.0..18.8 mm` 暗槽扣合）与驻波比实测为准。
