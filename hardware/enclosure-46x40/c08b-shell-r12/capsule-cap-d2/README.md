# C08B 胶囊底盖 D2 外扣版（2026-11-11）

Mako 看商用肌电手环后定：胶囊底扣一个盖子，正面 6 孔两排「大—小—大」，两条长边裙边包住表盘侧面卡住，两端敞开过表带；随后指出「第一个盖子是扣在表盘之外的」——电极层整段在表盘外面。所以胶囊段 FPC 不进 R13 底壳，贴在底壳外底下面，外面扣平底盖，和表带 D2（表带 → FPC → TPU 开孔层 → 铜片）是同一套叠法。

整机：最低点 Z −2.256，**总厚 10.10 → 12.36**。

## 为什么这样

- 上一版 FPC 在壳里平躺在槽底 Z 1.00，正上方就是 D17 底面件：U2 下叠放 −0.166、V4_FPC3 下 −0.086（库 3D 高度，未实测；R15 原板同样不过）。挪到壳外后 FPC 只剩尾巴从缝里竖直进壳，FPC 的 box_height 门转绿（尾巴对 V4_FPC3 0.703）。
- 胶囊底电极和表带同款、同凸出（1.2），偏置 / 参考略高。

## 文件

- `build.py`：按路径加载 R13 壳生成器（不改 R13），尾巴缝、串阻槽从 FPC geometry.json 读。
- `check.py`：孔对 FPC 焊盘（方块对角线要落在 Φ4.5 焊盘内）、铜片不撞、底盖与底壳不干涉、底盖顶到底壳外底正好两片 FPC（从 R13 原壳实测外底）、6 孔填平、尾巴缝开通、回折槽北壁、串阻槽让开且不挖穿、裙边 / 凸棱 / 卡槽、凸出；反例全红。
- `cap_d2_x2-X2D-TPU95A.3mf`：底盖 2 个，X2D 0.4、TPU 95A HF、0.08，约 24 分钟、3.3 g。底壳 `tray_d2` 走嘉立创 8001 光固化。

## 没做 / 没验

- R34 槽处底板只剩 0.35（嘉立创光固化建议 ≥ 0.8）：局部薄，靠底盖从下面托住；要加厚就把 R34 换 0402 或挪位。
- A 片没有 B 片叠着的地方，背面到底壳外底空 0.203，没做台阶。
- 汗从孔边渗入、卡扣松紧、尾巴实际弯折都要实物试；没打印、没装、没上人体。
