## 排线

```
[J1 南口] → 平出 1.4 mm（补强段）
    ↓ 上拱，过 J2 顶
[最高 z 7.3] → 南边下落，回折
    ↓
[J2 南口] 从南往北插入
```

- 折线平行 X 轴，导体 X 不变。两座都朝南，一个在顶面、一个在背面，所以 J2 第 n 脚对 J1 第 21−n 脚，`check_board.py` 按两板焊盘坐标核。
- 按聚硕 JS05A-20P-020-3-4（LCSC C22434842）建模：长 20、宽 10.5、补强 4。FH34 上下双面触点，同向反向都能插。露出段 14.7 + 插深 2×2.6 = 19.9，插深是假设，偏短就压低拱顶，拱顶到盖还有 2.6。
- 排线通过的区域，J1 和 J2 之间与 J2 以南，载板上没有贴片件，`check_board.py` 查。

## 没验证

- 排线到货要量：端头总厚 0.3，露铜和补强要对 FH34（规格书露铜 1.5±0.3、补强 2.5±0.3，或露铜 2.5±0.3、补强 ≥3.5）。料号尾 -3-4 若指露铜 3，超上限 2.8，这是推断，规格书正文没取到。回折内径上限 0.62，只折一次；FH34 耐久 20 次，没插线时不要合锁扣。
- 限位筋只算了几何。西筋实际靠 XIAO 板边受力，P44e 只叠上 0.05；按 20 N 假设估算应力约 65 MPa、挠度约 0.36 mm，和常见光固化树脂强度同量级，未实测。筋到电池和托架只隔 0.05，小于打印公差，首打要留修磨。盖的固定方式没写。P44e 没有安装孔，上下靠盖和泡棉，XIAO 到盖 0.5 这段能跳动。
- J2 到 H4 螺丝头名义 0.31，按规格书 A=12 算 0.085。螺丝头径不能超 φ2.8。
- 壳可打印性、USB 插头塑壳、线在板下的实际弯折、电池线焊点高度、M1.6 螺纹、托架强度、密封。
- 壳底凹槽只按理想圆腕和名义几何算，没打印、没试戴；实际手腕不是圆，软组织会变形。槽顶处壳底 0.5，强度没算。电池线穿过两板间 1.0 mm 夹层按线径 0.4 mm 假设留上下各 0.3 mm，实际用线外径应 ≤0.8 mm 以免顶撬 P44e。
- 板再下沉 0.4 可以减薄 0.4，电极也更好露出，但立柱变矮，这版没动。
