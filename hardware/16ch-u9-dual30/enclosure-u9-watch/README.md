| 项目 | 设计参数 | 说明 |
|---|---|---|

| **隐藏式四孔反锁** | 4 × `M1.4 × 8 mm` 自底壳外底沉孔盲锁入上盖 | 孔位严格读取双板实测同心坐标 `(NE +19.66,+16.33; SE +19.65,-16.45; NW -20.10,+16.33; SW -20.10,-16.39)`，完全位于盒底软板 `|X| ≤ 11.12 mm` 外侧；上盖顶面与四周零外露螺丝孔（盲孔顶壁 `0.90 mm`），底面沉孔由 `cap_bottom` 扣合遮蔽 |
| **东侧（`+X`）接口** | 直通沉板 Type-C 开口 + 防脱侧按按键帽 `side_button` | 对齐 `0.80 mm` 板厚下沉板 `USB1`（壳口下沿 `Z = 5.20 mm` 避让 `USB1` 底面 `Z = 5.396 mm`，去除易碎薄唇使 Type-C 插头护套直接贴合外侧壁）与 `U1` 侧按开关（静止间隙 `0.198 mm`，向内按压 `0.70 mm` 推入开关按头 `0.502 mm` 满行程，内侧防脱翼防拔脱） |
| **北侧（`+Y`）表带入口** | 双 30P 软板穿底长槽 + 回折袋 | `X = [-9.918 .. +7.606], Y = [17.990 .. 18.996]` 直读 `../strap-fpc-30p/geometry.json`，适配顶/底 `1.524 mm` 横向错位的双 30P 软板尾 |
| **表带生耳与贴肤底盖** | 南北 `22.30 mm` 快拆弹簧棒槽 + 外扣六孔盖 `cap_bottom` | 兼容标准 `22 mm` 快拆表带（小耳底面抬高至 `Z = 2.00 mm` 防顶手腕）；外扣底盖开 `4 × Φ6.50 mm` 圆孔 + `2 × 3.50 × 3.50 mm` 方孔，6 颗镀金电极铜片齐平凸出 `1.200 mm` |
