# 16ch 旗舰双板（`MCU-U9 + AFE-30P`）圆润手表外壳 `enclosure-u9-watch`

状态：**已实现未实物验收**（`build123d` 参数化生成、全量 `338 + 588` 个板级真实三维实体逐个刚体变换布尔零干涉 + 5 项必交反例自检通过；待首件 3D 打印试装）。

## A · 关键尺寸链与结构设计

| 项目 | 设计参数 | 说明 |
|---|---|---|
| **俯视外廓** | `46.80 × 40.00 mm`，四角 `R3.80 mm` | 上盖顶面大圆角 `R2.40 mm`，底壳底边圆角 `R0.70 mm`，内腔 `44.40 × 37.60 mm`（`R2.20 mm`，壁厚 `1.20 mm`） |
| **垂直叠层高度** | 壳体净高 `10.40 mm`（`Z = 0.15 .. 10.55 mm`） | 得益于 `AFE-30P` 升级 `1.00 mm` 超薄双面接触 30P 连接器（`C324727`）与 `0.80 mm` 板厚，较 `2.00 mm` 高连接器基线减薄逾 `2.0 mm`；含外扣底盖与 `1.20 mm` 凸出电极尖端总高 `12.806 mm`（`Z = -2.256 .. +10.55 mm`） |
| **隐藏式四孔反锁** | 4 × `M1.4 × 8 mm` 自底壳外底沉孔盲锁入上盖 | 孔位严格读取双板实测同心坐标 `(NE +19.66,+16.33; SE +19.65,-16.45; NW -20.10,+16.33; SW -20.10,-16.39)`，完全位于盒底软板 `|X| ≤ 11.12 mm` 外侧；上盖顶面与四周零外露螺丝孔，底面沉孔由 `cap_bottom` 扣合遮蔽 |
| **东侧（`+X`）接口** | Type-C 开口 + 防脱侧按按键帽 `side_button` | 对齐 `MCU-U9` 的 `USB1`（含插头塑胶护套沉台）与 `U1` 侧按开关（静止间隙 `0.198 mm`，向内按压 `0.70 mm` 推入开关按头 `0.502 mm` 满行程，内侧防脱翼防拔脱） |
| **北侧（`+Y`）表带入口** | 双 30P 软板穿底长槽 + 回折袋 | `X = [-9.918 .. +7.606], Y = [17.990 .. 18.996]` 直读 `../strap-fpc-30p/geometry.json`，适配顶/底 `1.524 mm` 横向错位的双 30P 软板尾 |
| **表带生耳与贴肤底盖** | 南北 `22.30 mm` 快拆弹簧棒槽 + 外扣六孔盖 `cap_bottom` | 兼容标准 `22 mm` 快拆表带（小耳底面抬高至 `Z = 2.00 mm` 防顶手腕）；外扣底盖开 `4 × Φ6.50 mm` 圆孔 + `2 × 3.50 × 3.50 mm` 方孔，6 颗镀金电极铜片齐平凸出 `1.200 mm` |
