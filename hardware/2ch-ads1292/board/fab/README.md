## F 下单后手工

1. 掰板，磨平连接筋残留：东西边只有 0.25 mm 余量，残留超过这个数就进不了壳。
2. 电极件未定，手焊到底面。首选低温锡膏加热台，顶面 SAC305 不会重熔。
3. P44e、XIAO、排线见上层 README E 节。
4. 首次上电前量 3V3–GND。

## G 检查

```bash
KPY=/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/Current/bin/python3
zsh pull_jlc.sh            # 拉嘉立创封装和符号到 .jlc/（不进仓库），限流就再跑一次
zsh rebuild.sh "改了什么"   # 绑新 blob → 拼板 → 转角核对 → BOM/CPL → 自检 → 拼板 DRC → 图
```

`rebuild.sh` 在转角全过时把新 blob、两个 SHA-256 写进 `rotation.source.json`，`make_smt.py` 才放行。`board/final.sh` 每跑一次板的 uuid 都变，板定稿后要再跑一次。库存按日期存 `stock-*.jsonl`，后查的盖前面的。

`check_fab.py`：zip 对拼板重导一致；铜、阻焊对源板无丢失，多出的全在板外；锡膏开窗数，底面 0；PTH = 过孔；NPTH = 4 孔 + 邮票孔 + 定位孔；BOM、CPL 对真源；5 个破坏反例都报。
