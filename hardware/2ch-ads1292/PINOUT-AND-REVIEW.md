## B. 两枚辅助触点（`E3` / `E6`）偏置限流路径与单故障安全电流核算

1. **偏置电路拓扑**：
   - `U1` (`ADS1292IPBSR`) 的 `RLDIN/RLDREF`（28 脚）、`RLDINV`（29 脚）、`RLDOUT`（30 脚）配置为内部 `AVDD/2 = 1.50 V` 基准驱动；`RLDINV`（29 脚）与 `RLDOUT`（30 脚）之间并联反馈网络 `C3 (1.5 nF) ∥ R15 (1 MΩ)`，设定右腿驱动环路带宽约 `106 Hz`。
   - `RLDOUT`（30 脚）先串联 **`R13` (`300 kΩ` 0603)** 到达中间保护节点 **`NRLD`**，由 **`D3` (`ESD501DPYR`)** 对 `GND` 作双向 TVS 钳位。
   - 从 `NRLD` 节点分出两条独立支路：
     - 北路经 **`R14` (`620 kΩ` 0603)** 接北排中间辅助触点 **`E3`**（网名 `E3_RLD`）；
     - 南路经 **`R16` (`620 kΩ` 0603)** 接南排中间辅助触点 **`E6`**（网名 `E6_RLD`）。
2. **IEC 60601-1 单一故障直流患者辅助电流核算（限值 `≤ 10 µA d.c.`）**：
   - **单枚辅助触点贴肤（仅 `E3` 或仅 `E6` 接触）**：串联总阻值 $R_{\text{single}} = 300\,\text{k}\Omega + 620\,\text{k}\Omega = 920\,\text{k}\Omega$；在最高电源轨 `3.30 V` 下，最大电流为 $3.30\,\text{V} / 920\,\text{k}\Omega = 3.59\,\mu\text{A} < 10\,\mu\text{A}$。
   - **两枚辅助触点同时贴肤（`E3` 与 `E6` 并联接触人体）**：并联等效总阻值 $R_{\text{dual}} = 300\,\text{k}\Omega + (620\,\text{k}\Omega \parallel 620\,\text{k}\Omega) = 300\,\text{k}\Omega + 310\,\text{k}\Omega = 610\,\text{k}\Omega$；在 `3.30 V` 下最大总电流为 $3.30\,\text{V} / 610\,\text{k}\Omega = 5.41\,\mu\text{A} < 10\,\mu\text{A}$。
   - **单颗电阻短路单一故障**：若 `R14` 短路，仍有 `R13 (300 kΩ)` 限流；若 `R13` 短路，单触点仍有 `R14 (620 kΩ)` 限流（`3.30V / 620kΩ = 5.32 µA < 10 µA`）。
   - **四路采样触点（`E1/E2/E4/E5`）**：每路均为 `1 MΩ (0603) + 1 MΩ (0402) = 2.0 MΩ` 两颗独立电阻串联；正常工作直流限流 `1.65 µA`，单颗电阻短路故障下仍剩 `1.0 MΩ`（`3.30 µA < 10 µA`）。

## D. 固件寄存器配置（`firmware/xiao-ads1292-2ch`）与离体上电 8 测点总表

### 1. `firmware/xiao-ads1292-2ch` 关键寄存器初始化值（对照 `BRINGUP-CHECK.md`）
- **`ID` (`0x00`)**：期望读出 `0x53`（`ADS1292`）或 `0x73`（`ADS1292R`）。
- **`CONFIG1` (`0x01`) = `0x02`**：连续转换模式，采样率 **`500 SPS`**（`DR = 010b`）。
- **`CONFIG2` (`0x02`) = `0xA0`（正常，bit7=1、开启内部 `2.42 V` 参考缓冲 `PDB_REFBUF=1`、`VREF_4V=0`）/ `0xA3`（内部 1Hz 测试方波）**。
- **`LOFF` (`0x03`) = `0x10`**（保留复位值 bit4=1）。
- **`CH1SET` (`0x04`) / `CH2SET` (`0x05`) = `0x00`（正常增益 6）/ `0x01`（输入短接测底噪）/ `0x05`（内部方波自检）**。
- **`RLD_SENS` (`0x06`) = `0x20`（仅开启 `PDB_RLD=1` 缓冲器）/ `0x23`（首测接入 `CH1` `RLD1P/RLD1N` 共模反馈环）**。
- **`RESP1` (`0x09`) = `0x02`**（TI 手册 p.60 强制要求对 ADS1291/1292 写入 `0x02`）；**`RESP2` (`0x0A`) = `0x07`**（`RLDREF_INT=1` 选内部 `AVDD/2`，bit2/bit0 置 1）。
