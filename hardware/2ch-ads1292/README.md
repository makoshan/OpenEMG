## B 电路取舍

| 项 | 取法 | 原因 |
|---|---|---|
| 电极 | E1 CH1+、E2 CH1−、E4 CH2+、E5 CH2−，E3、E6 辅点接 RLD | Mako 11-04 定电极贴 PCB 底面、**不穿板**；11-10 定照 C08B 盒底 6 触点，两路各用一对电极。C08A 仍按 10-30 定的双极 |
| 输入腿 | 电极 → 1 MΩ → ESD → 1 MΩ → ADS，不接下拉 | ESD 短路时电极仍隔 1 MΩ；第一颗用 0603，贴着电极放 |
| RLD | RLDOUT → 300k → NRLD（ESD）→ 620k → E3，另一路 620k → E6；反馈 1 MΩ∥1.5 nF，内部 AVDD/2 | 两个辅点都贴着是 610 kΩ，5.5 V 口径 9.0 µA；只贴一个是 920 kΩ、6.0 µA，都低于 10 µA |
| 29 脚 | 经 100 kΩ 接 RLDOUT | 同 TI 评估板；可把 RLD 路由到通道测量 |
| AVDD | TPS7A2030 3.0 V，由 3V3 供，常开 | 不能切：切 AVDD 而 DVDD 还在，AVDD−DVDD≈−3.3 V，超手册下限 −2.1 V |
| DVDD | 3V3 过磁珠 | 同 TI 评估板 |
| 主控 | J2 接 P44e，XIAO 焊在 P44e | Mako 11-06 定；J2 脚 n = P44e J1 脚 21−n |
| PWDN/RESET | 接 P44e PWDN_N（D4），串 4.7k | P44e 这根有 10k 下拉，默认低；RESET_N 不引到 J1 |
| START | 接 P44e START（D3） | P44e 有 10k 下拉；用命令启动，也留了硬件启动 |
| DRDY | 接 P44e DRDY_A（D6） | 转接板只引出 D6 |
| CS | 接 P44e CS_A（D7） | P44e 有 10k 上拉，本板不能再下拉 |
| USB 互锁 | XIAO 5V → J1 19 脚 → 排线 → J2 → R32 0R → Q1 把 ADS 拉进硬掉电 | 默认生效。台架要插 USB 读 ADS 时拆 R32。栅极下拉 R25 是 10 kΩ（Mako 11-12 定，原 100 kΩ）：电池态 XIAO 5V 脚的漏电要到约 70 µA 才会误开 Q1 |
| AVDD 回读 | R26 → J2 → D5 | D0 被 P44e 上拉占了 |

## C 贴法

贴片 47 件全在顶面，含 J2。手焊：E1–E6（底面）。P44e 另做：背面 J1 和阻容回流，XIAO 烙铁焊 14 个邮票孔。

## D 不提供的接口

- 电池：线焊 XIAO 背面 BAT+/BAT−，穿 P44e 槽从主控侧引向电池，不经本板铜，本板也不开窗穿线。
- SWD：P44e 不做，只能 USB 刷机。

## E 组装顺序

1. 板贴好后掰板，磨平连接筋。
2. 电极手焊到底面。
3. P44e 背面贴 J1 和阻容。电池线先焊 XIAO 背面，线头穿 P44e 槽，再焊 14 个邮票孔。
4. 排线一头插 J2 南口，折过 J2 上方。P44e 翻开，J1 朝上插另一头、合锁扣，再翻回落位，电池线从 P44e 槽沿北侧引出接电池（不被两板夹住）。J1 落位后埋在 1 mm 的缝里，插不了线。
5. 首次上电前量 3V3–GND；只接电池时量 R25 1 脚要为低，否则 Q1 常开，ADS 一直在复位（XIAO 5V 脚电池态电平未实测）。

结构见 R7：XIAO 中心同直焊版，USB 开口在东墙，比 R5 抬高 1.8，盒总厚 10.66。

## F 待定

- 串阻是候选，等 R01 对比（`docs/r01-ch1-ch2-compare-20261104/`）。
- 单故障文档 [`SINGLE-FAULT.md`](SINGLE-FAULT.md) 已写，实测未做；要过 EXR1 同类门槛才能贴肤：没有下拉，RLD 是唯一直流偏置，RLD 关闭的 EXT1 路径不可用。
- USB 线物理拔掉仍是贴肤使用条件：互锁不隔离市电路径。贴肤门槛：R32 贴着，且插 USB 实测 TP8 为低。
- 第一颗电阻前的铜没有限流；汗液路径靠电极圈密封，见单故障文档 D 节。
- 4.7 nF、1.5 nF 和 VCAP 是 X5R/X7R，腕带有麦克风效应风险（手册建议有振动时用 C0G 或钽）。
- 上电时 TPS7A20 软启动，AVDD 会落后 3V3，AVDD−DVDD 瞬间可能低于 −2.1 V（工作条件，不在绝对最大值表里），首板用示波器看。

## G 固件约束（硬件靠它才成立）

- 新写 ADS1292 驱动（候选流式固件见 [`../../firmware/xiao-ads1292-2ch/`](../../firmware/xiao-ads1292-2ch/README.md)，已通过跨板引脚 20/20 对账、48 项单测与 PIO 编译，默认双硬件锁保持关闭，未上板）；两路补成 V12 的 8 路 27 字节帧，主机加 VREF 2.42 V、增益配置。V4 固件不能直接刷。
- 脚：D6 DRDY、D3 START、D4 PWDN/RESET、D5 AVDD 回读、D7 CS、D8 SCLK、D9 MISO、D10 MOSI；D0、D2 被 P44e 上拉，不用；D1 空。
- CONFIG2：开 PDB_REFBUF，VREF_4V=0；RESP2 写 0x07：手册要求 bit2、bit0 写 1（默认 0x02 不满足），bit1（RLDREF_INT）保持 1，写 0 会让 29 脚成正反馈。
- PDB_RLD 默认关要打开；上电等 1 s 再发复位脉冲；寄存器读写时 SCLK ≤1.024 MHz。
- RESP1 写 0x02：手册第 60 页原话「For the ADS1291 and ADS1292 devices, 02h must be written to the RESP1 register」，复位值是 00h（11-11 功能复核补）。
- CONFIG2 bit7 保持 1（复位值 0x80），开基准缓冲写 0xA0；LOFF bit4 保持 1（复位值 0x10）。
- 复位脉冲宽 ≥1 tMOD，固件定 10–100 µs；手册 §8.5.1.8 写拉低超过 2^9 个 fMOD 周期（128 kHz 下约 4 ms）就进掉电，不是复位（11-11 复核改正，原写 2^10）。
- 固件读 nRF 的 VBUS 检测：有 VBUS 就把 D4 拉低并拒绝采集，补上 R32 之外的第二道（VBUS 检测未实测）。
- D5 作 ADC 输入，不要初始化 Wire（D5 也是 SCL）；台架比 D5 读数和 TP1，差值应 <50 mV。
- START 用命令模式，别拉高；D4 高时 P44e 的 10k 下拉多耗 0.33 mA。
- RLD_SENS 首测只选 CH1：推算裕度 65–89°；CH1、CH2 全选 40–72°，要先过假人体振荡检查。
- 离体台架：测 CH1 把 E1、E2 和一个辅点短接，测 CH2 把 E4、E5 和一个辅点短接，RLD 开；或用内部短路。其他接法输入浮空，读数无效。
