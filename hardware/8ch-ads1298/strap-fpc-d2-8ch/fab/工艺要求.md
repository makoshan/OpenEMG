# D2-8CH 单片四层表带软板 — 嘉立创 FPC 打样与 SMT 工艺要求

样品打样，非量产。开工前请做 CAM 工程确认，如有制程疑问请暂停联系我们，勿自行改动铜线或合并异网焊盘。

| 项目 | 工艺参数要求 |
|---|---|
| 板名 / 包络 | `strap-d2-8ch`，单片外形包络 `105.20 × 26.20 mm`，按 `strap-d2-8ch-Edge_Cuts.gm1` 激光切割成型 |
| 层数 / 基材 | **4 层软板（FPC）**：`F_Cu` / `In1_Cu`（AGND 网格地）/ `In2_Cu`（AGND 网格地）/ `B_Cu`；无胶压延铜 PI 基材 |
| 柔性区总厚 | 标称 **`0.203 mm`**（含双面覆盖膜）。尾端 34P 金手指处加上 B 面 `0.10 mm` PI 补强后总厚 **`0.30 ± 0.03 mm`**（配 HRS FH34SRJ-34S-0.5SH 翻盖座） |
| 覆盖膜 | 黑色或黄色 PI 覆盖膜，双面按 `F_Mask.gts` / `B_Mask.gbs` 开窗 |
| 表面处理 | **沉金（ENIG）1–2 µin**（贴肤焊盘与金手指同面沉金，禁止喷锡） |
| **B 面分厚 PI 补强（共 2 种厚度，均贴在 B_Cu 外侧，Gerber 均为顶视不镜像）** | 1. **`0.10 mm` PI 补强（含胶）**：按 `strap-d2-8ch-BOT_STIFF_0p10mm_PI.gbr`（仅尾端 34P 金手指背面 `2.5 × 17.5 mm` 1 块，使插头总厚达 `0.30 mm`）；<br>2. **`0.20 mm` PI 补强（含胶）**：按 `strap-d2-8ch-BOT_STIFF_0p20mm_PI.gbr`（表带触点背面 `Φ7.2 mm` 圆岛 12 块 + 胶囊段背面带 6 个矩形避让窗的垫片 1 块，共 13 块；6 个窗口必须镂空露铜/露覆盖膜以容纳 B 面串阻 `R1–R4 / R33 / R34`）。对照图示见同目录 `stiffener-map.png` |
| 最小线宽 / 线距 / 过孔 | 最小线宽 `0.15 mm`，最小间距 `0.15 mm`；金属化过孔 69 个（钻孔 `0.25 mm` / 焊盘 `0.50 mm`），非金属化孔 0 个 |
| 字符 | 双面白字，按 `F_Silkscreen.gto` / `B_Silkscreen.gbo` |
| 电测 | 100% 飞针电测，网表按 `strap-d2-8ch.d356`（37 个网络，88 个焊盘） |
| SMT 贴片（可选随单） | 双面仅贴 **18 颗限流串阻**（见 `jlc_smt_bom.csv` + `jlc_smt_cpl.csv`：嘉立创基础库 `C25741` 100kΩ 0402 × 16 颗 + `C25811` 200kΩ 0603 × 2 颗；F 面 `R5–R16` 共 12 颗，B 面 `R1–R4, R33, R34` 共 6 颗） |
| **钢网特别说明（必读）** | `F_Paste.gtp` 共 42 个开孔（含 F 面 12 颗 0402 电阻的 24 个小焊盘 + 18 个 `Φ6.5 / Φ4.5` 贴肤铜片大焊盘）：<br>- **若随单由嘉立创 SMT 只贴 18 颗电阻（铜片由我们收货后二次焊接）**：请 CAM 制作 SMT 钢网时**删去 `F_Paste.gtp` 上 18 个 `Φ6.5 / Φ4.5` 大圆电极开孔**，F 面钢网只保留 `R5–R16` 的 24 个 0402 焊盘，避免大圆锡膏空印污染；<br>- **若自备铜片一并回流焊**：保留全部开孔，建议阶梯或 `0.10 mm` 激光钢网 |
| 整面背胶 | **不要整面 3M 背胶**（仅上述两份补强层自带热压胶贴合 PI 补强片） |
