# 背面开放的一体 TPU 内衬

状态：已实现未实物验收。继承 F04 原板框、19.6 mm 排距、13 mm 触点间距；软板和已下单制造文件均未改。

**2026-10-14方案更新：** 当前采用平顺TPU＋外围薄胶固定，三扣边版停止推进。按[装配与用胶说明](ASSEMBLY_GUIDE.md)执行：先无胶干装，再做单片胶材验证，固化后再装电子件。下方几何与文件继续沿用。

## A｜结构与厚度

取消整块0.7 mm底座，把框和触点座合为一体。每排软板岛背面补一片6×23×0.2 mm绝缘补强（材料和刚度待验证），另有0.05 mm板胶及0.15 mm织带胶假设。

| 参数 | 名义尺寸 |
|---|---:|
| TPU面至背缘 | 2.356 mm |
| 金属突出贴肤面 | 0.500 mm |
| 含胶、不含织带 | 3.006 mm |
| 含假设1.2 mm织带 | 4.206 mm |
| 连续TPU内衬 | 172.4×28 mm |
| 排间连接薄面 | 0.4 mm |

相比上一版3.506 mm减少0.500 mm；没有用压缩弹片来减薄。圆片9×1.2 mm保持原规格。

## B｜装配顺序

1. 打印TPU空壳。`shell-print.stl`为单排，`liner-print.stl`为整条一体内衬；已按贴肤面朝平台、背面开口朝上放置。金属和电路不参与打印。先验证单排。
2. 圆片从**正面**放入承台，外围环胶固定，背面中间Φ7窗口给弹片接触。圆片不能从背面穿过Φ7窗口，不能硬塞；本版没有浮动行程。
3. 核对实际弹片焊脚后，在有支撑的软板上焊接，背面加局部补强。焊接冷却且电气检查后再入TPU。
4. 将内衬背面朝上，整条F04连同弹片和补强从背面放入；桥经过向背面敞开的槽。`loading.step`用整体下移展示该路径。
5. 先干装确认每个触点接触高度和导通，再以外缘胶及补强背胶固定到织带。胶不进入弹片与圆片接触区。织带承担拉力，FPC不作拉带。

图中金属、弹片、补强和胶均为独立零件；**只有TPU壳是一件打印件**。织带厚度与胶材未定，尾端补强已保留，尾部到外置R01连接及扣具仍待实物布局。

## C｜文件

- `assembled.step`：连续TPU、整条F04、17触点及织带平展装配。
- `loading.step`：背装状态，织带暂不装；整条软板、弹片和补强一起离开壳体。
- `row.step`：双触点单排完整装配。
- `liner.step`、`shell.step`、`rld-shell.step`：连续壳、单排壳、RLD单孔壳。
- `shell-print.stl`、`liner-print.stl`：打印朝向网格，未切片、未发打印。
- `build.py`、`check.json`：参数化源与本轮检查。

## D｜验证边界

已检查双触点/RLD名义无交叠、背装连续保守扫掠与封底必碰反例、圆片正面装入和下穿承台反例、连续内衬为一个有效实体、6个STEP回读。

BW0041BG真实脚位、弹臂和允许压缩尚未核实，模型仍沿用S7231名义1.2 mm工作包络，不能保证现有BW可直接焊装。TPU触点承台刚度、胶防脱、0.2 mm补强效果、打印公差、0.4 mm连面耐弯与长期舒适未实测。圆片固定，弹片仅导电。

先验证一排：干装及露出高度 → 接触电阻随轻压/弯动是否稳定 → 补强及粘接保持 → 才扩大为整条。几何通过不等于佩戴或制造放行。
