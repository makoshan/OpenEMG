## B 连接与焊接

`[17枚金属触头] → S7231弹片 → FPC铜线 → J18焊线尾 → R01 J3同号焊孔`

看`wiring.csv`：J18:1–17分别接R01 J3:1–17，18–20不接。每个N独立，不能并地；RLD独立。尾部空间顺序不是针号顺序，必须核丝印。17根线是电极信号线，不是XIAO转接线；R01→XIAO沿用既有方案，尾线进壳及抗拉仍待配合验证。

保留已核原厂焊盘的Harwin S7231-45R：左0.4×1、右1.2×1、上下0.3×0.2铜区，同一弹片四铜区同网。TE2329497-2尚缺原厂焊盘，不能在此板替换。先在平直工装焊弹片和尾线，查短路和17路连续性，再装到底座；不在织带或电池旁回流。焊料高度0.10是空间假设，钢网/回流温度由料件及工厂确认。3D里弹片是空间包络，不是原厂变形模型。

## C 粘贴与装配

1. `tpu-carrier`底朝下打印；`petg-support`承力底朝下，`petg-guide`／`rld-guide`以文件朝向打印（盖唇贴平台）。先只做一排，不能把金属触头换成打印塑料当电极。
2. TPU底座内放PETG承力底；用0.05胶层粘6×23软板岛，弹片朝皮肤。柱位于软板两侧，不穿板。
3. Φ9×1.2 的 304 无孔圆片从导向盖内侧装入。盖的内侧口袋 Ø9.4，皮肤侧留 Ø8、厚 0.4 mm 的边，圆片掉不出去；圆片正面比这圈边低 0.4 mm。背面仍在旧法兰底面，弹片预压不改。先对准两枚弹片，保持预压，再粘盖与支撑边框；实际装盖夹具和胶固化过程待试配。不得把胶粘到导向孔或弹片。
4. 每排底面以0.15胶层粘29 mm织带，中心对齐、排距19.6；各排间留4 mm底座间隙。5 mm软板桥不整面粘死。尾线焊点单独固定抗拉，不能靠焊点拉住织带。

胶材料未选定，0.05/0.10/0.15厚度均为假设；需在实际织带和TPU上测剥离、弯曲与耐汗。桥不贴死也不等于已经解决弹性织带伸长。`bent-concept.step`先按每排局部平面从岛边走到底座外，再以端点弦线跨间隙，仅说明排布，不证明长度、应变和寿命；不含尾端进壳弯曲。
