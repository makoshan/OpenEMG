# 8 通道同尺寸圆角上下叠板配置（`stacked-d20-8ch`）

为了实现 **2ch / 8ch / 16ch 100% 共用同一个上层主控（`R4U6`）、同一个 `43.10 × 36.50 mm` 板框与同一个 `46 × 40 mm` 圆角外壳（`R12`）**，8 通道穿戴叠板直接采用 `D20` 采集板的**单面贴片配置**：

- **制板 Gerber / KiCad 源 / 嘉立创 `.epro2`**：直接复用 [`../../16ch-c08b-round/afe-d20/`](../../16ch-c08b-round/afe-d20/) 与 [`../../16ch-c08b-round/jlc-eda/`](../../16ch-c08b-round/jlc-eda/)。
- **单面 SMT 贴片清单**：使用本目录的 `jlc_smt_bom_8ch.csv` 与 `jlc_smt_cpl_8ch.csv`——**仅贴装 Top 顶面 76 颗元件**（完整包含 `J_AFE`、`V4_LM27762` ±2.5V 电源、`V4_X1` 晶振、主片 `V4_U1 ADS1298`、`V4_FPC1` 34P 座及 CH1–8 全套 ESD/滤波/去耦），**Bottom 底面 51 颗从片元件全部空贴（DNP）**，直接省去双面高密贴片费与整套从片物料成本。
- **自动完整性校验**：运行 `python3 verify_8ch_dnp.py` 可自动核对顶底网表归属与必失败反例。
