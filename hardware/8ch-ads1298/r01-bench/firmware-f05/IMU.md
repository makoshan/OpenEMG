# F05 IMU 软件候选

状态：已实现未实物验收。源码只在 `.`。保留 R01 板与 AFE 锁；没有刷机。

## A 数据路径

`ADS1298 → SPI → 肌电通知000002 → events.jsonl → 现有DSP回放`

`XIAO Sense内部LSM6DS3TR-C → TWIM1后台传输 → IMU通知000006 → imu-events.jsonl → imu.csv`

两路分别收包，共用 MCU 计数器；未测传感器滤波延迟、中断延迟和实际对齐误差。不是已经验收的同步系统。

| 数字 | 候选配置／限制 |
|---|---|
| IMU | 标称104 Hz；加速度±8 g、角速度±1000 °/s；标称0.244 mg/码、35 mdps/码，未校准 |
| 时钟 | TIMER2，1 MHz、32位；主循环扩成64位，每71.58分钟至少读一次。1 µs是分辨率，精度未测 |
| BLE | IMU整包36字节，至少MTU39；后台队列拥塞不分片、不阻塞ADS读取 |
| 默认构建 | 原8档不启IMU；`ads_2k_imu`、`ads_4k_imu`为另2档实验候选，AFE仍锁定 |

## B 线与时间

板包实际映射：IMU供电数字脚15→P1.08，SCL16→P0.27，SDA17→P0.07，INT1 18→P0.11。不是J1上的额外引线。
TWIM1不调用忙等的Wire1；实际构建中ADC全局SPI使用SPIM3，与TWIM1分开。
TIMER2捕获通道0给ADS中断、1给IMU中断、2给主循环。SDK初始化已读走bootloader暂存的CC0；构建检查SDK未启TIMER2驱动。

肌电时标仍为首帧ISR服务时间＋后续标称周期。IMU时标为INT1的ISR服务时间；`read_latency_us`是该ISR到本轮检查读完成时的主循环时差，不包含已实测的传感器群延迟。两路不能据此宣称微秒级物理同步。

## C 协议

UUID前缀为`7b24c101-3948-4f03-9d11-12bb9d`；原5个特征布局保持不变。

| 新特征 | 内容 |
|---|---|
| 000006 | IMU通知，36字节 |
| 000007 | IMU状态，只读64字节 |

IMU通知全为小端：0–3字节为版本1／类型2／样本数1／标志；4为32位序号；8为64位ISR时间；16为gyro XYZ与accel XYZ共6个有符号16位原码；28为新鲜度3；29–31必须0；32为32位读取检查延迟。
标志与肌电同义：bit0合成来源、bit1会话开始、bit2配置切换。真实IMU不设bit0。原肌电解码器仍拒类型2，不能混进ADS滤波链。

状态0–3为版本1／启用1／活动／故障，4为WHOAMI，5为8 g，6为1000 °/s，8为104 Hz，12为ISR时间种类1，13–15为0（没有对齐实测证明）。16起依次为6个64位值：观察到的沿数、产出、发送、弃包／不确定事件、通知失败、最后ISR时间。故障0–7依次为无、总线、身份、回读、读取超时、过载、新鲜度、停止超时。沿数不是精确丢样数。

## D 启停与拒绝

`上电等待 → WHOAMI/地址探测 → 复位 → 配置逐项回读 → 稳定等待 → 开INT1 → 新鲜度检查 → 收包`

| 能做／不能做 | 条件 |
|---|---|
| ✓ `IMU1`独立模式 | 只订IMU；不调用ADS启动，不绕AFE锁；仍须明确设备、构建ID与离体授权 |
| ✓ 联合模式 | 两路均订阅；ADS锁通过才能启动；任一路退订／故障，停止两路 |
| ✓ `STOP`／断连 | 禁止新事务，异步等硬件STOPPED，再关外设／供电；停止超时仍报告活动 |
| ✗ 旧读数／漏沿冒充新样本 | BDU、自增、脉冲DRDY；两种新鲜度都要满足；poll后重新核沿数再通知 |
| ✗ 尾包丢失假成功 | 电脑最终样本数必须等于设备发送数，产出必须等于发送；已知丢样／未知队列溢出均失败 |

## E 复现入口

在仓库根目录：`python3 host/check_v12_imu.py`。执行真实C++状态机与寄存器后端，再经外部蓝牙替身、生产接收、原包、真实CLI回放；不接设备。
现场只读入口沿用`host/v12_ble.py status`；IMU单独采集使用`--mode imu`，联合在原ADS模式后加`--with-imu`。两者均需`--allow-real --expected-build-id`，默认ADS锁不会自动打开。
回放：`python3 host/v12_imu.py 新采集目录 --out 新文件.csv --allow-real`。肌电继续用原回放；不跨缺口补值或插值宣称对齐。
