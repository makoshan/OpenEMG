# V12-R01 外接接口

65×60×1.6mm 离体调试板，三只连接器均从板上方插入。它不替代原50×30mm可穿戴板，也没有完成线束、插头外壳与整机的实物配对。

| 接口 | 板端已落图 | 对手与未决项 |
|---|---|---|
| J1 | Samtec TST-108-01-L-D，2×8，2.54mm | 具体母插头/线束与XIAO Sense实物版本未定；不得套用现成IDC线序 |
| J2 | JST B2B-PH-K-S，2针，2mm；1=VBAT，2=GND | PHR-2线端；实际电池含保护板型号、极性、尺寸未核 |
| J3 | Molex 43045-2012，2×10，3mm | 43025-2000线端壳，端子/线径和实际压接未核；1–10一排，11–20另一排 |

## J1 逐线定义

这是转接线定义，不是将16针连接器直接套在XIAO排针上的定义。

（注意：J1 朝向按版图坐标核对，XIAO 背面 BAT± 焊盘位置以实物丝印为准。）

| J1脚 | 信号 | XIAO端 |
|---:|---|---|
| 1 | 3V3 | 3V3 |
| 2 | GND | GND |
| 3 | XIAO_SCLK | D8 |
| 4 | XIAO_MISO | D9 |
| 5 | XIAO_MOSI | D10 |
| 6 | XIAO_CS | D7 |
| 7 | XIAO_DRDY | D6 |
| 8 | XIAO_RESET | D2 |
| 9 | XIAO_CLKSEL | D1 |
| 10 | ANA_EN | D0 |
| 11 | AVDD_SENSE | D3 |
| 12 | VBUS | USB 5V检测；接高会经Q1强制关闭模拟电源 |
| 13 | VBAT | BAT+；禁止未经核对并接两路电源 |
| 14 | GND | GND |
| 15 | XIAO_PWDN | D4，默认低 |
| 16 | OE_N | D5，只输入，不开内部上下拉；低不等于DVDD/VCAP1已稳定 |

J3：1/2=CH1 P/N，3/4=CH2 P/N，依次到15/16=CH8 P/N，17=E_RLD，18–20不接。现有ESD在线路限流电阻之前接地，单故障人体路径尚未放行。
