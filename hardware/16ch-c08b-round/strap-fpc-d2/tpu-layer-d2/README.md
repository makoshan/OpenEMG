# C08B 表带电极层 D2（2026-11-11）

Mako 定：「TPU 直接贴到表带上方，不需包裹成品表带；一层表带，一层 FPC，一层 TPU，TPU 开口，贴镀金铜片」。取代同日的独立电极豆路线（`../../pod-d1/`）。

## 叠层（从表带往皮肤）

| 层 | 厚 | 作用 |
|---|---|---|
| 现成战术表带 25 宽 | 约 1.6（假设） | 不改 |
| PI 补强（焊盘背面） | 0.20 | 防 FPC 在铜片边折断；0.20 与叠放的 B 片带（约 0.203）等高，16 个岛在表带上一样平 |
| FPC（背胶贴表带，焊盘朝皮肤） | 0.11 | 导电：焊盘 → 走线 → 胶囊插座 |
| 0.1 双面胶（9448A，按 TPU 同样开孔） | 0.1 | 把 TPU 粘在 FPC 上（复核 P1：只靠孔挂会脱落） |
| TPU 开孔层（本件） | 0.8 | 盖住 FPC 不碰皮肤；铜片卡在孔里，顺便定位 FPC；背面 28 个浅槽藏 FPC 皮肤面的 0402 串阻 |
| 镀金铜片 Φ6 × 2.0 | 凸出 1.2 | 电极，焊在 FPC 焊盘上（H62 镀金实心圆铜片 Φ6.0 × 2.0 mm（镀金层 ≥ 1 µm）） |

导电路径：皮肤 → 铜片 → 焊锡 → FPC 焊盘 → FPC 走线 → 胶囊插座 → 采集板。TPU、PI、表带都不导电。

## 布局

- 11-11 Mako「改回原来方案，触点在表盘底部」：CH1 / CH2 两对和 BIAS / REF 两个辅助触点在胶囊底（同 R15 / R13 壳孔位），表带上 14 路。北片 2 路（CH3 Y 34、CH4 Y 42），南片 12 路（Y −32 … −120），节距 8，同一路 P/N 中心距 18（25 宽表带放 Φ6，铜片离带边 0.5）。
- 分两片是因为表带短段的日字扣环不剪（Mako 11-11），层不能压在扣环上。北片离带端圆筒 6.35、离扣环 13.05（扣环中心按离北生耳 55 估，**假设**，没量）；南片离带端圆筒 4.8。
- TPU 层宽 26.2（比表带每边多 0.6），孔 Φ6.5（比铜片大 0.5，先焊铜片再套 TPU 要能 28 孔同时套进），孔边、端壁 0.85，层厚 0.8。北片 26.2 × 16.2，南片 26.2 × 96.2。

## 串阻浅槽与方向切角（11-11「修不平」）

- 串阻从 FPC 表带面挪到皮肤面后，每岛两颗 0402 落在两个铜片之间。本层背面（贴 FPC 那面）每颗一个 2.16 × 1.24、深 0.45 的槽（串阻高 0.35 是假设），槽顶剩 0.35（两层）。槽位不抄数，直接读 `../geometry.json` 的 `f_res_pockets`。
- 每岛两个槽关于岛中心点对称，整片转 180° 槽仍对得上；但 TPU 翻面（镜像）就对不上。北端 +X 角切 1.5 的 45° 角当方向键：贴的时候槽面朝 FPC、切角在北端 +X 一侧，防止翻面贴。
- 坐标：TPU 层 Z 朝皮肤，表带 X = 50 − FPC 板 y、Y = 58 − 板 x（右手系，行列式 +1）。第一版用了 R13 的 X = 板 y − 50，是镜像，复核抓到；`check.py` 的 `res_fit` 自己按右手系把 28 颗串阻外框放进 TPU 实体核落槽，镜像反例判红。

## 装法

1. 铜片在加热台上回流焊到 FPC 焊盘（先万用表逐片测通）。
2. FPC 背胶贴到表带皮肤一侧，对准位置。
3. 9448A 按纸样开 28 个孔和 28 个串阻槽窗（胶不开窗会被串阻顶起），先贴到 TPU 层背面；再把 TPU 从铜片上套下去（孔比铜片大 0.5），压实粘到 FPC 上。

## 打印与检查

- `layer_d2-X2D-TPU95A.3mf`：北南两片一盘，平放，X2D 0.4、TPU 95A HF、0.16 标准，约 17.5 分钟、2.30 g（加槽后重切）。
- `check.py`：整片 0.5 mm 网格三层扫（铜片投影内全空、孔外全实，抓针孔、沉孔、锥孔、凹坑、槽、多孔），孔用铜片实物径探，单实体、包围盒、离带端圆筒和扣环、规格门；Mako 定的 PN 18、节距 8、Φ6×2、北 2 南 12 位置写死在 `EXPECT`，改设计要两边一起改。反例全红（`checks.json`，含复核造的漏判）。
