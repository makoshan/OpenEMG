# 表带软板 D2：配合「表带电极层 D2」的四层 34P 双片（2026-11-11）

**状态：已实现未验收。** 本机 DRC 两片 0/0（含重铺）、几何、脚序、对孔、壳外方案的尾巴缝检查全过（`checks.json` 30 项门全部 `ok`，`fails: []`；11-11 晚「胶囊段移到底壳外」改版，见 §0000）；未打样、未焊铜片、未插 D17、未贴肤、未装底盖。基于 R15（`v12/c08b-d17-fpc34-4l-r15-meta18-20261108/`）生成器改写。R15、R12、D17、TPU 层、制造包、订单都没动。

叠层（表带 → 皮肤）：25 mm 表带 → 本软板（背胶贴表带，F 面焊盘朝皮肤）→ 0.8 TPU 开孔层（孔 Φ6.5，`tpu-layer-d2/`）→ Φ6×2.0 镀金铜片回流焊在 F 面焊盘上。

## 11-12 REF 挪到 A 片（Mako 定）

辅点铜片改方形 3×3×2（Φ4×2 买不到）后，B 片 EB2 焊盘比 A 片低一层，REF 只凸出 1.0、其它 1.2。REF（BIAS_DRV12）只在 B 尾 FPC3 34 脚有，A 尾 FPC1 没这个脚，不改 D17 就不能在 A 片单走。做法：A 片 EB2 位置原 Φ4.9 让位孔换成 **EB2A**——Φ4.5 焊盘、Φ0.8 金属化孔、两面开窗；B 片 EB2 焊盘贴在它背面同心，装配时 A/B 叠好对正、从 A 片 F 面往孔里灌锡把两片焊通，再焊铜片。6 个贴肤焊盘都在 A 片 F 面，同高。

- 新门 `eb2_joint`：读两块板实物，EB2A 与 B 片 EB2 同心 ≤ 0.01、同 Φ4.5、同网 BIAS_DRV12_E、金属化孔 0.6–1.0、两面开窗、A 片附近无板边孔；反例「右移 0.05」「网改 AGND」全红。
- `stack_clearance` 撤掉「A 让位孔 vs B 的 EB2」一项（现在是有意对焊）。
- 全部门绿，DRC A/B 0/0。
- 未验：灌锡对焊没试；焊点厚度没算进叠层；锡要灌到和焊盘持平，鼓包会把方块铜片垫斜，焊完先量高再焊铜片。EB2A 故意不开 F 面钢网（锡膏不进孔）；内层 AGND 到焊盘 0.151（规则 0.15）。

## 5. 未验证

- 未打样、未回流 Φ6×2.0 铜片（铜片热容大，FPC 上回流能否焊透、会不会偏位、钢网开口是否要缩，都没试）。
- 未与 TPU 层实物套装（只做了坐标对孔）；FPC 26.2 宽 = TPU 层宽，比 25 mm 表带每边宽 0.6，上表带后边缘是否翘没看。
- 串阻改到 F 面后被 0.8 TPU 盖住：TPU 背面的浅槽（`f_res_pockets`）还没加进 TPU 层生成器，槽深、TPU 贴合后串阻会不会被压、汗液会不会顺槽渗到串阻，都未验证；0402 高 0.35、本体 1.0×0.5 是假设。
- 表带侧「等高」只是按标称厚度算（PI 0.20 含胶、板厚 0.203、背胶厚度没算），实物平整度未量；A 片 CH5–8 岛下是 B 片带子 + PI 圆片两种支撑，中间 0.8 的缝隙悬空。
- 岛间只开下沿缝，弯折手感、PI 圆片间 0.5 的折痕寿命未测；PI 厚度 0.20/0.10 含胶是假设。
- B 片 CH9–11 分叉对偏离中线 2.66/1.86/1.06，P 腿靠 B 面回头弯补长 4.67/3.07/1.47 mm，电气上等长但没测串扰/共模。
- 原始贴肤阻抗、汗液短路、电极触感都未测。
