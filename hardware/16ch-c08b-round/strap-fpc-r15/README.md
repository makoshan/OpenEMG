# R15 表带软板：D17 采集板 34P、四层、盒外 14 岛对内 18.0 mm（Meta 专利参考，2026-11-08）

**状态：已实现未验收（未打样、未插实物）。** 基于前序 R14 迭代，将**盒外 14 个电极岛（北 2 岛 CH3–CH4 + 南 12 岛 CH5–CH16）**的对内（同路 P/N，沿前臂肌纤维纵向）中心距从 `16.0 mm`（`y = 42.0 / 58.0 mm`）外扩至 **`18.0 mm`（`y = 41.0 / 59.0 mm`）**，同时将盒外岛外形高收窄至 **`21.2 mm`（`y = 39.4–60.6 mm`，补强高 `20.8 mm`）**，完美适配卡尺实测的 **`22.04 mm` 表带**（两侧各留 `0.42 mm` 余量，同时也兼容 `25 mm` 表带）；保持**盒底 2 对（CH1/CH2，`16.0 mm`）+ 2 辅助（EB1/EB2）及串阻原位不动**（100% 兼容透明光固化外壳 `../../enclosure-46x40/c08b-shell-r12/` 与 `c08b-shell-r13-notch/` 的 `22.30 mm` C 形生耳槽），并保持**腕周节距 `8.0 mm`**（16 路跨度 `166.8 mm`，适配 `≥ 162 mm` 腕围）。

生成：KiCad 自带 python3 跑 `build.py`（两块板 + 填好的 GND 平面 + pro/dru + `d17-interface.csv`、`geometry.json`、`match.json`）→ `check.py`（全部检查，写 `checks.json`，有失败退出码 1）→ 系统 python3 跑 `preview.py`（PNG）。每次重跑 UUID 会变，以 `checks.json` 里的 `board_sha256` 为准。
