# C08B 电极小节 D1 整条（2026-11-11）

Mako 在三个方向里选了「电极小节 + 现成表带」的 D1：电极从胶囊里拆出来，做成 16 个 TPU 小节，套在 25 mm 战术带上，胶囊只装电路。同日 Mako 定电极为「FPC 沉金焊盘 + 焊一片 Φ6.5×1.0 镀金铜片 + 小节背后垫泡棉」，又说「TPU 凹槽，可以连接成一个整体」：16 节连成一整条，一次打印、一次穿带。

## 为什么拆出胶囊

- 胶囊装不下弹簧顶针：采集板背面 6 个触点位置都压在 U2（底面 ADS1298）和阻容上，背面器件最低到 Z 1.24，壳底内表面在 1.00–1.20（R13 `boards-real-frame.json`）。
- 参照 Meta sEMG-RD（bioRxiv 2024，Extended Data Fig.1）：「pogo-pin style」Φ6.5 镀金黄铜电极，双极中心距 20 mm，16 路；neurband：FPC Φ6.5 沉金焊盘 + 6×2 EVA 泡棉点。

门：`check.py` 对单节和整条都核。单节：凹槽三层扫泡棉径、深度看中心加一圈、带槽整宽带侧移净空、唇边、斜撑、底座、包围盒、规格门。整条：单实体、包围盒、每一节平移到原点逐节跑单节几何门（节距不均也会红）、每个缝中段全高全空、桥只在 13.6–15 且只有 0.6 厚。反例全红（`checks.json`）。三轮独立复核抓到的漏判都补成了反例。

## 装法

1. 铜片用加热台回流焊到 FPC 焊盘上（32 片，买 2 包 40 片；结算 Mako 自己来）。
2. 泡棉点贴进 32 个凹槽，FPC 铜片对准凹槽贴上。
3. 唇边开口 23.6 比带宽 25 窄：从魔术贴那一端把整条穿上去（扣环那端过不去）。

## 只适配腕围 182

节距按 Mako 腕围 182 定死，整条加胶囊 181.2，只剩约 0.8。腕围更小节会挤、桥会拱；更大只能在胶囊两侧留缝，且电极不再对准原来的肌群。给别人戴要按对方腕围改 `WRIST_MAKO` 重出，腕围小于约 170 要换 D2（Φ5 电极、节更窄）。

## 没定 / 没做

- 表带实际厚度、泡棉点实物尺寸要量；都没打印、没试戴。
- 桥只有两端两座 0.6 × 1.4，穿带拉直、前臂锥度会拉它；反复弯和扭转没试。
- FPC 只靠泡棉胶固定；新表带 FPC（16 桨片，节距 8.875）没画，画时加锁定孔或点胶位。
- 偏置和参考电极放哪没定：胶囊底保留两个平触点，或某一节做三电极。
- 以后可以改硅胶整体浇注（铂金硅胶，FPC 开孔锁胶），先用这条 TPU 把尺寸和电极试出来。
