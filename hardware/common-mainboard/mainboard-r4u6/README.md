# 共用双核主控板 R4U6（圆角螺丝孔版 · 适配 2ch / 8ch / 16ch 下层采集板）

> **验证状态**：已实现未实物验收（嘉立创 DRC 通过，413 脚逐脚对板 0 差，首轮打样途中）。

## 核心文件清单

| 文件 | 说明 |
|---|---|
| `C08B-main-R4U6.epcb2` | 嘉立创 EDA Pro 4 层源板文件（`43.10 × 36.50 mm`，四角 `R4.6 mm` 圆角） |
| `C08B-main-R4U6-gerber.zip` | 生产 Gerber 包（4 层 `0.6 mm`，盘中孔须选**树脂塞孔 + 电镀盖帽**） |
| `jlc_smt_bom.csv`、`jlc_smt_cpl.csv` | SMT 贴片清单与坐标（109 颗、47 种物料；`R211` 与 `JP701` 不贴装） |
| `polarity-top.png`、`polarity-bottom.png` | 顶底面极性与第 1 脚核对图 |
| `r4u6-readback.json` | 从 `.epcb2` 读回的全板焊盘网络表（供原理图与固件自动核对） |

> **必读安全红线**：东北角安装孔底面 `VBUS` 距孔壁 `0.183 mm`，**必须使用外径 ≤ Ø2.0 mm 的尼龙/塑料绝缘支柱配尼龙 M1.4 螺钉**（详见 [../../../SAFETY.md](../../../SAFETY.md)）。
